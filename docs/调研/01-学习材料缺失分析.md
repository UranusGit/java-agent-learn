### 新增企业级项目

**企业项目三：Agent 控制中心**
- 管控分离：控制面（管理、配置、监控）vs 数据面（Agent 执行）
- 历史记录持久化：完整的会话+工具调用+LLM调用存储
- 工具调用可视化：时间线视图 + 调用链路图
- Trace 全链路：从用户请求到每一步 LLM 调用
- Agent 配置中心：Prompt/模型/参数热更新
- 灰度发布：按租户/按流量百分比切换 Agent 版本

**企业项目四：AI 运维自治平台**
- 基于 SRE Agent 的自治系统
- 告警接入 → 自动调查 → 根因分析 → 修复确认
- 完整的 MCP Hub 实现
- Durable Execution 持久化执行
