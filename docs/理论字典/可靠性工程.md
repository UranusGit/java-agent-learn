# 理论字典：可靠性工程

> Java 工程师的最大护城河——Agent 可靠性本质是分布式系统问题。

| 概念 | 一句话解释 | 分布式对应 |
|------|---------|-----------|
| **幂等性** | 同一操作执行多次效果相同 | 接口幂等 |
| **持久化执行** | 每步 checkpoint，崩溃可恢复 | Saga/Workflow |
| **重试** | 失败后自动重试 | Retry Pattern |
| **补偿** | 部分失败后回滚已执行操作 | Saga 补偿 |
| **熔断** | 连续失败时停止请求保护系统 | Circuit Breaker |
| **三重保护** | maxTurns + 美元预算 + 死循环检测 | — |

## 四层可靠性
```
工具级：幂等 + 错误返回
查询级：重试 + 超时
系统级：熔断 + 降级
执行级：Temporal 持久化
```
