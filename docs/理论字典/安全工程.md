# 理论字典：安全工程

| 概念 | 一句话解释 |
|------|---------|
| **Prompt Injection** | 通过输入劫持 LLM 执行非预期操作（OWASP LLM Top 1） |
| **直接注入** | 用户直接在输入中写恶意指令 |
| **间接注入** | 攻击藏在文档/网页中，Agent 读取后被劫持 |
| **工具劫持** | 通过注入让 Agent 调用不该调用的工具 |
| **人在回路** | 高危操作必须人工确认 |

## 四层防御
```
输入过滤 → 权限隔离 → 输出审查 → 人在回路
```
