# 理论字典：框架选型

| 框架 | 定位 | 什么时候用 |
|------|------|---------|
| **Spring AI 2.0** | Spring 生态 AI 框架（主框架） | 80% 场景 |
| **LangChain4j** | LangChain 的 Java 版 | Quarkus 项目 / 入门对照 |
| **Spring AI Alibaba Graph** | 多 Agent 编排引擎（国内生态） | 复杂多 Agent |
| **LangGraph4j** | 多 Agent 状态机（社区） | 研究/实验 |
| **Temporal** | 持久化执行引擎 | Agent 可靠性 |

## 选型决策
```
80% 场景 → Spring AI 2.0 单框架 + Workflow 模式
Quarkus 项目 → LangChain4j
复杂多 Agent → Alibaba Graph
需要持久化 → Temporal
不要混用 Spring AI + LangChain4j
```
