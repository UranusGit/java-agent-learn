# 理论字典：成本工程

| 概念 | 一句话解释 | 节省效果 |
|------|---------|---------|
| **Prompt Cache** | 缓存固定 prompt 部分，第二次起省 90% | 50-90% |
| **语义缓存** | 语义相同的问题直接返回缓存结果 | 20-40% |
| **模型路由** | 简单走小模型，复杂走大模型 | 30-60% |
| **上下文裁剪** | 裁剪不必要的历史和工具定义 | 10-30% |
| **Tool Masking** | 只注册当前任务需要的工具 | 10-20% |

## 四层优先级
先做 L1（Prompt Cache）→ L2（语义缓存）→ L3（模型路由）→ L4（上下文裁剪）
