# 理论字典：RAG 原理

| 概念 | 一句话解释 |
|------|---------|
| **RAG** | 检索增强生成：先检索相关文档，再让 LLM 基于文档回答 |
| **Embedding** | 把文本变成向量（语义指纹），用于相似度检索 |
| **向量库** | 按语义相似度查询的特殊数据库（HNSW/IVF 索引） |
| **分块（Chunking）** | 把长文档切成小段，提高检索精确度 |
| **Recall@K** | Top-K 检索结果中有没有正确文档（检索质量指标） |
| **Faithfulness** | LLM 回答是否忠于检索文档（生成质量指标） |
| **Hybrid Search** | BM25（关键词）+ 向量（语义）混合检索 |
| **Re-ranking** | 用 Cross-encoder 对检索结果重新排序 |

## RAG 五步链路
加载 → 分块 → 向量化 → 入库 → 检索生成
