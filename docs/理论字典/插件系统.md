# 理论字典 · 插件系统

> 速查概念，不展开实践细节。

---

## 核心概念

**插件系统**是一种软件架构模式，允许在不修改核心代码的情况下，通过外部模块扩展系统功能。

## 插件 vs 微服务

| 特征 | 插件 | 微服务 |
|------|------|--------|
| 部署方式 | 同进程加载 | 独立进程 |
| 通信方式 | 方法调用 | 网络 |
| 隔离性 | 类加载器隔离 | 进程级隔离 |
| 延迟 | 纳秒级 | 毫秒级 |
| 适用 | 工具扩展 | 服务拆分 |

## 核心机制

- **SPI（Service Provider Interface）**：Java 标准，`META-INF/services/` 声明实现
- **ClassLoader 隔离**：每个插件独立 CL，避免依赖冲突
- **生命周期**：发现 → 加载 → 校验 → 初始化 → 运行 → 销毁
- **沙箱**：限制插件的资源（CPU/内存/网络/文件系统）

## 知名插件系统

- **Minecraft Bukkit**：游戏服务器插件
- **VS Code Extensions**：IDE 插件
- **Jenkins Plugins**：CI/CD 插件
- **ChatGPT Plugins / GPTs**：AI Agent 插件

## 关键设计原则

1. **稳定的核心 API**：接口不能频繁变动
2. **最小权限**：插件只获得必需的权限
3. **失败隔离**：插件崩溃不影响核心
4. **版本兼容**：用语义化版本号管理兼容性
