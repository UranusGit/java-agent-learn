---

## 项目目标

```
用户提交 .java 文件
    ↓ Routing：检测语言 → 路由到 Java 评审员
    ↓ Parallelization：bug / 风格 / 安全 三个维度并行分析
    ↓ Orchestrator-Workers：编排器动态汇总
    ↓ Evaluator-Optimizer：评估报告完整性 → 改进 → 直到通过
    ↓ Prompt Chaining：串接全流程
输出：结构化评审报告
```

**复用前面学的能力**：
- P2 的 RAG（评审时检索编码规范）
- P2 的评估方法论（评估评审报告质量）
- 五大 Workflow 模式
- Agent 防失控三重保护
- MCP Server（把代码评审工具暴露出去）
- Prompt Injection 防御

### Step 2：整合所有模式的评审服务

```java
@Service
public class CodeReviewService {

    private final ChatClient chatClient;

    // 完整评审：用满五大模式
    public String fullReview(String code) {
        // 1. Routing: 检测语言
        String language = detectLanguage(code);

        // 2. Parallelization: 三个维度并行
        var bugF = CompletableFuture.supplyAsync(() -> analyzeBug(code));
        var styleF = CompletableFuture.supplyAsync(() -> analyzeStyle(code));
        var securityF = CompletableFuture.supplyAsync(() -> analyzeSecurity(code));

        CompletableFuture.allOf(bugF, styleF, securityF).join();

        // 3. Orchestrator: 汇总
        String combined = combine(bugF.join(), styleF.join(), securityF.join());

        // 4. Evaluator-Optimizer: 评估并改进（maxIter=3）
        String report = combined;
        for (int i = 0; i < 3; i++) {
            if (evaluateCompleteness(report)) break;
            report = improveReport(report);
        }

        return report;
    }
    // ... 各方法实现参考 02-五大Workflow模式.md
}
```
