## A2A（Agent-to-Agent）协议

| 协议 | 作用 | 成熟度 |
|------|------|--------|
| **MCP** | Agent 连接工具/数据 | ✅ 可用（已学） |
| **A2A** | Agent 之间通信 | 🔬 2-3 年内跟进 |
| **ACP** | Agent 通信协议 | 🔬 实验中 |

**MCP vs A2A 的关系**：
```
MCP = Agent 的"手"（连接工具和数据源）
A2A = Agent 的"嘴"（Agent 之间对话）
```

## AgentOS（Agent 操作系统）

12-24 个月方向——统一的 Agent 运行时：
- Agent 生命周期管理（创建/调度/销毁）
- 资源隔离（CPU/内存/网络）
- 权限沙箱
- Agent 间通信总线

> **当前阶段**：了解概念即可，不要投入实现。等生态成熟后再跟进。
