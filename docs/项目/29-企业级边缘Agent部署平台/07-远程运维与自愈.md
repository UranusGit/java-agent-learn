# 07-远程运维与自愈

> **定位**：让上百节点**免跑现场**——**① 边缘遥测（批量/压缩/断网缓存上报）② 分级告警（节点级/组级/全局）③ 自愈动作（重启/OOM 清理/模型回滚/配置重置）**。呼应 [33-部署运维](../../教程/33-部署与运维.md)、[28-可观测](../../项目/28-企业级Agent统一可观测平台/00-需求分析与架构设计.md) 思想。前置阅读：[06-边缘安全与设备信任](06-边缘安全与设备信任.md)。
>
> **铁律 0**：遥测/自愈编排自研「概念代码」（复用 Observation 思想下沉）。

---

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①边缘遥测（低带宽批量+断网本地缓存补传）②告警分级（单节点自愈/组级关注/全局应急）③自愈剧本（常见故障的确定性恢复动作） |
| **影响了哪些模块** | 新增 EdgeOps；节点 → 自愈执行器 |
| **架构如何演进** | 边缘运维从"跑现场"演进为"剧本化自愈+远程介入" |
| **上一版痛点** | 节点 OOM 要人去重启；告警洪水无分级 |

**本迭代验收**：①心跳/遥测覆盖率 ≥99%（00 验收③）②常见故障自愈率 ≥80%（远程替代现场 ≥95%，00 验收⑤）③断网期间遥测不丢（缓存补传）。

## 二、自愈剧本（常见故障）

| 故障 | 自愈动作 |
|------|---------|
| 推理进程 OOM | 重启+清缓存+降并发 |
| 模型加载失败 | 双槽自动回滚上一版（03） |
| 磁盘将满 | 清旧日志/旧模型包（保双版本） |
| 遥测中断>1h | 标记失联→组级告警（02） |

**纪律**：自愈是**确定性剧本**（不是 LLM 自由发挥——运维动作要可预测，呼应 09-AIOps 同结论）；自愈失败升级人工工单。

## 三、验收

| 测试 | 期望 |
|------|------|
| 注入 OOM | 自愈重启+告警记录 |
| 模型损坏 | 自动回滚 |
| 断网期间事件 | 恢复补传不丢 |
