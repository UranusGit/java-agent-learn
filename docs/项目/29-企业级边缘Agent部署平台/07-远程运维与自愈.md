## 二、自愈剧本（常见故障）

| 故障 | 自愈动作 |
|------|---------|
| 推理进程 OOM | 重启+清缓存+降并发 |
| 模型加载失败 | 双槽自动回滚上一版（03） |
| 磁盘将满 | 清旧日志/旧模型包（保双版本） |
| 遥测中断>1h | 标记失联→组级告警（02） |

**纪律**：自愈是**确定性剧本**（不是 LLM 自由发挥——运维动作要可预测，呼应 09-AIOps 同结论）；自愈失败升级人工工单。

### 二.1 本节测试与验证（遥测 / 分级告警 / 自愈剧本）

**前置条件**：`EdgeOps`（批量+压缩+断网缓存上报）已实现；分级告警（节点/组/全局）已接；自愈执行器能落地确定性剧本。

**材料——剧本内含的旋钮**：OOM→`重启+清缓存+降并发`；模型加载失败→`双槽回滚上一版`；磁盘将满→`清旧日志/旧模型包（保双版本）`；遥测中断>1h→`标记失联→组级告警`。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 注入推理进程 OOM | 自愈动作触发（重启+清缓存+降并发）并记录告警 |
| 2 | 构造模型加载损坏 | 自动双槽回滚到上一版本（03 联动） |
| 3 | 构造磁盘将满 | 清旧日志/旧模型包，保留双版本槽 |
| 4 | 断网期间产生遥测事件 | 事件本地缓存，恢复后补传不丢（覆盖率/失联判据生效） |
| 5 | 统计自愈成功率与遥测覆盖 | 常见故障自愈率 ≥80%；心跳/遥测覆盖 ≥99%（00 验收③⑤） |

**失败排查**：①OOM 无自愈→剧本未绑定进程监控或执行器未落；②模型损坏不回滚→双槽健康检测未判 rollback；③磁盘清理删了双版本→清理逻辑未保留当前/上一版；④断网遥测丢→缓冲未持久化或补传无游标；⑤告警洪水→分级（节点/组/全局）未降噪。
