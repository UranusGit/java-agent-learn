## ADR-01：两级架构

**决策**：云端管节点组（分发/策略），组内节点对等协作（08），不逐节点直管。

**背景**：百级节点直管风暴；组是业务自然边界（门店/产线）。

**取舍**：组主选举复杂度，换管理面收敛。

## ADR-02：分发三件套

**决策**：分层（registry→区域→节点）+断点续传+带宽预算+金丝雀灰度+双槽回滚。

**背景**：GB 级包×百节点的风暴与风险。

**取舍**：分发链复杂，换专线安全与发布可控。

## ADR-03：断网显式降级

**决策**：分层降级 + 用户显式告知"离线模式"。

**背景**：静默失败/装正常摧毁信任。

**取舍**：体验坦诚（承认受限），换信任与预期管理。

## ADR-04：端云三层分工

**决策**：记忆本地热+云全量同步；上下文网络态切换托管；协作以受限 AgentCard 参与。

**背景**：全本地失全局、全云断网瘫。

**取舍**：同步一致性成本，换两头兼顾。

## ADR-05：四道防线

**决策**：设备凭证/mTLS、落盘加密、包验签、远程擦除。

**背景**：边缘物理暴露（可被盗/伪造/篡改）。

**取舍**：密钥管理开销，换物理面安全。

## ADR-06：确定性自愈

**决策**：自愈=预定义剧本（重启/回滚/清理），失败升级人工；不用 LLM 自由运维。

**背景**：运维动作必须可预测（LLM 自由发挥在运维=灾难）。

**取舍**：剧本覆盖有限（常见故障80%），换可预测性。

## ADR-07：局域联邦

**决策**：同组节点互援（强帮弱推理/知识代理/组主协调）。

**背景**：弱节点卡死强节点闲；单点知识不全。

**取舍**：组通信复杂度，换资源利用率。

## ADR-08：TCO 对照决策

**决策**：节点级 TCO 台账 + 云边同负载对照，作为负载去留依据。

**背景**：边缘经济账不清导致盲目铺或盲目撤。

**取舍**：归集成本，换数据化决策（呼应 44）。

## 决策代价回顾

- ADR-02 分发链 = 建设复杂度（区域仓运维）。
- ADR-04 同步 = 冲突处理成本（端写优先缓解）。
- ADR-07 联邦 = 组协议维护（标准 mDNS 缓解）。
