# 05-端云分工与数据同步

> **定位**：端云**三层分工框架**——**① 记忆（本地高频+云同步）② 上下文（端轻云全）③ 协作（边缘 Agent 作为受限 A2A 节点）**，加**同步纪律**（冲突/带宽/隐私）。呼应 [55-§6](../../教程/55-边缘Agent与端云协同部署.md)、[31-端云](../../项目/31-企业级Agent上下文管理平台/10-端侧与边缘上下文.md)。前置阅读：[04-断网自治与分层降级](04-断网自治与分层降级.md)。
>
> **铁律 0**：分工框架/同步自研「概念代码」。

---

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①记忆分片（本地热记忆+云端全量，增量同步）②上下文托管切换（网络好云端接管）③边缘 AgentCard（标注低算力/离线容忍约束）④同步冲突处理（端写优先+时间戳） |
| **影响了哪些模块** | 记忆/上下文供给 → 端云双源；协作注册 → 边缘约束标注 |
| **架构如何演进** | 从"全本地或全云"演进为"按层按网络态动态分工" |
| **上一版痛点** | 记忆只在云（断网失忆）/只在端（跨设备丢）；云端把任务委给无算力的边缘节点 |

**本迭代验收**：①断网记忆本地可用、恢复同步 ②上下文按网络态切换装配 ③边缘 AgentCard 带资源约束（委托方避坑）。

## 二、三层分工

| 层 | 端 | 云 | 同步 |
|----|----|----|------|
| 记忆 | 高频个人/设备记忆 | 全量+跨设备 | 增量/端写优先 |
| 上下文 | 轻量装配（确定性） | 混合压缩全套 | 网络态切换 |
| 协作 | 受限节点（AgentCard 标约束） | 完整中继 | 约束可见 |

## 三、验收

| 测试 | 期望 |
|------|------|
| 断网记偏好 | 本地保存恢复后同步 |
| 网络好 | 上下文升云端混合压缩 |
| 委托到边缘 | 委托方看到算力约束 |
