## 二、三层分工

| 层 | 端 | 云 | 同步 |
|----|----|----|------|
| 记忆 | 高频个人/设备记忆 | 全量+跨设备 | 增量/端写优先 |
| 上下文 | 轻量装配（确定性） | 混合压缩全套 | 网络态切换 |
| 协作 | 受限节点（AgentCard 标约束） | 完整中继 | 约束可见 |

### 二.1 本节测试与验证（三层分工与数据同步）

**前置条件**：端云双源（本地热记忆+云端全量）与增量同步已实现；上下文按网络态切换装配已接；边缘 Agent 已带约束的 AgentCard 注册。

**材料——分工表内含的同步纪律**：记忆=增量/`端写优先`；上下文=按网络态切换；协作=`约束可见`（AgentCard 标注低算力/离线容忍）。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 断网期间在本地记一条偏好 | 本地热记忆保存成功；云端不丢失既有数据 |
| 2 | 恢复网络后触发同步 | 本地新偏好增量同步到云端全量（端写优先，不覆盖更早时间戳） |
| 3 | 网络好时发起上下文装配 | 上下文升级为云端混合压缩全套（网络态切换生效） |
| 4 | 委托方查看边缘节点 AgentCard | 能看到资源约束（低算力/离线容忍），避免把高负载任务委给弱边缘节点 |

**失败排查**：①断网记偏好同步时丢失→本地热记忆未持久化或恢复无增量；②端写优先被云覆盖→时间戳/优先级逻辑颠倒；③网络态切换不生效→上下文装配未感知网络态信号；④委托前看不到约束→AgentCard 资源标记未随注册发布。
