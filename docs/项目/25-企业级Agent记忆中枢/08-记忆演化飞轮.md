## 二、采用信号 + 差记忆归因

```java
// 概念代码：召回采用信号（响应式埋点）
public void trackRecallUsage(String runId, List<MemoryRecord> recalled, Set<String> usedIds) {
    for (var r : recalled) {
        boolean used = usedIds.contains(r.id());
        signalStore.incr(r.id(), used ? POSITIVE : NEGATIVE);   // 正/负信号
    }
}
// 高负信号记忆 → 归因（是过时/错误/文不对题?）→ 修复建议
```

**指标**：每记忆召回采纳率 = 被用次数 / 被召回次数。采纳率跌破阈值 → 该记忆进"待审"（08 修复/06 衰减）。

### 二.1 本节测试与验证（采用信号 + 差记忆归因）

**前置条件**：`trackRecallUsage(runId, recalled, usedIds)` 已把正/负信号写入 `signalStore`；能构造"某记忆被多次召回仅少数被采用"的数据。

**材料——信号核对**（直查信号存储 `signal_store` 的 id 与正/负计数，无外部端点）：

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 对一批召回 `trackRecallUsage`（其中 M1 高频被采用、M2 高频落选） | M1 采纳率接近 1.0；M2 采纳率跌破设定阈值 |
| 2 | 触发差记忆归因流程 | M2 被标记"待审/修复建议"，进 §三/06 的修复或衰减管线 |
| 3 | 核对指标口径 | 采纳率 = 被用次数/被召回次数 计算正确，可对每记忆查询 |

**失败排查**：①信号统计错→`usedIds` 匹配逻辑错误或 `incr` 涨错计数；②阈值不触发→归因阈值定死或状态流转未实现。

## 三、主动记忆挖掘（从对话沉淀）

```java
// 概念代码：从会话沉淀可复用记忆（LLM 抽取候选 + 人工/规则确认）
public void mineFromConversation(String convId, ChatClient client) {
    List<String> conv = shortMem.get(convId).stream().map(Message::getText)...;
    // 用实体抽取/LLM 打分：哪些是"可长期复用的用户偏好/事实/结论"
    List<MemoryCandidate> cands = client.prompt()
            .system("从对话抽取可跨会话复用的用户偏好/事实/结论，输出 JSON list")
            .user(conv).call().entity(/* List<MemoryCandidate> */);
    for (var c : cands) { if (c.confidence() >= THRESHOLD) longRepository.saveAll(c); }   // 高置信入库
}
```

**要点**：不是每句话都存（那会是噪音），只沉淀**高置信、可复用**的记忆；结合 06 分数做后续演化。

### 三.1 本节测试与验证（主动记忆挖掘）

**前置条件**：`mineFromConversation(convId, client)` 已实现（LLM 抽取候选 + `confidence() >= THRESHOLD` 高置信入库）；`ChatClient` 按实证基座调用。

**材料——挖掘核对**（对一段含明确偏好的会话触发挖掘，观察入库集合）：

```text
会话内容：含"我喜欢深色主题""我的公司是 ACME""今天天气不错"等混排句子
```

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 触发 `mineFromConversation` | 只有高置信可复用项（偏好"深色"/事实"ACME"）被 `saveAll`，噪音句（"天气不错"）不被沉淀 |
| 2 | 核对置信门槛 | `confidence() < THRESHOLD` 的候选未入库（不每句都存） |
| 3 | 重复触发同一会话 | 结合 03 去重键，已沉淀项不重复入库（幂等） |

**失败排查**：①噪音全入库→抽取/打分未过滤或阈值过低；②该沉淀的漏了→`THRESHOLD` 过高或抽取 prompt 未覆盖偏好/事实/结论；③重复入库→`saveAll` 未走 03 去重。
