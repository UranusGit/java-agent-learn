**三层审计价值**：①合规（谁读了用户记忆）②安全（越权扫描）③运营（记忆被用情况，供 08 飞轮）。

## 三、越权/异常告警

- 越权尝试（05/09 拦截的）→ 告警 + 审计。
- **高频访问**（同 scope 短时间大量读写，疑似爬取/攻击）→ 限流 + 告警。
- **数据量异常**（某 tenant 记忆量突增）→ 告警（存量/成本治理视角）。

## 四、召回缓存 + 索引提速

```java
// 概念代码：召回两级缓存(热点 + 索引)
public List<MemoryRecord> cachedRecall(String scope, String query, int topK) {
    String key = scope + ":" + sha256(query) + ":" + topK;
    // 一级 Caffeine 进程缓存(热) + 二级 Redis 共享缓存(冷) —— 响应 04/08 高频召回
    return caffeine.get(key, k -> redis.get(key, k2 -> hybridRecall(scope, query, topK)));
}
```

**注意**：缓存 **scope 维度 key**（多租户不漏读，呼应 05）；记忆变化/删除时**失效对应 key**（呼应 07 遗忘权，删记忆后缓存也立失效）。
