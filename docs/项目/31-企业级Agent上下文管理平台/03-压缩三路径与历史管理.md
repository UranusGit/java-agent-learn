## 二、三路径与选择

```java
// 概念代码：历史压缩三路径
public List<Message> compress(List<Message> history, int budget) {
    int len = estimate(history);
    if (len <= budget) return history;                          // 不需要压缩
    return switch (policy()) {
        case WINDOW  -> window.keepRecent(history, budget);      // 保近丢远(零成本,丢信息)
        case SUMMARY -> summarizer.rollup(history, budget);       // 全摘要(保要点,有成本)
        case HYBRID  -> hybrid(history, budget);                 // 旧摘要+新原文(最优)
    };
}
List<Message> hybrid(List<Message> h, int budget) {
    int cut = findCut(h, budget - RESERVE_RECENT);   // 分界:预算外的是"远期"
    String digest = summarizer.summarize(h.subList(0, cut));       // 远期→摘要
    return List.concat(userMsg(digest), h.subList(cut, h.size())); // 摘要头+近期原文
}
```

**选择规则**：短超载用窗口（免费）；长会话/重要上下文用混合（成本换信息）；全摘要仅在"必须整体极简"场景。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 历史 `len ≤ budget`，`policy=任意` | 原样返回（`return history`，不触发压缩/摘要） |
| 2 | 50 轮长会话、`policy=HYBRID`、预算紧 | 输出 `fit` 预算；远期（cut 之前）被摘要成头，近期保留原文 |
| 3 | `policy=WINDOW` | 保留最近对话，远期被丢弃，零摘要调用（免费） |
| 4 | 远期关键信息验证（混合） | 关键事实出现在摘要头中（摘要保要点，不因丢远而丢失） |
| 5 | 触发成本 | 只在 `len > budget` 时才发生摘要调用（阈值为界，非每轮） |

**失败排查**：①长会话仍爆窗→`hybrid` 的 `findCut` 未预留 `RESERVE_RECENT`；②摘要丢了关键信息→`summarize` 提示词未要求保留实体/决策；③每轮都摘要→`len <= budget` 早早 return 未生效。
