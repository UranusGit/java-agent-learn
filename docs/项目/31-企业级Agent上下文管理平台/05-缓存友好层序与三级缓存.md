## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①装配输出按稳定度排序（系统→工具→记忆摘要→RAG→用户）②语义缓存（相似输入复用答案，阈值+高风险禁用）③检索缓存（query→结果，知识更新失效） |
| **影响了哪些模块** | render → 层序固化；新增三级缓存 |
| **架构如何演进** | 装配从"能装"演进为"装得缓存友好" |
| **上一版痛点** | 用户输入混在中间导致前缀全变，KV 全失效；相似问题重复推理 |

**本迭代验收**：①层序稳定（同会话前缀不变）②KV 命中率提升 ≥30%（00 验收③）③语义缓存高风险场景禁用。

## 二、层序与三级缓存

```java
// 概念代码：稳定层序渲染 + 三级缓存
public String renderCacheFriendly(List<ContextLayer> layers) {
    return layers.stream()
        .sorted(comparing(ContextLayer::volatility))   // 波动性升序:最稳在前
        .map(ContextLayer::content).collect(joining()); // 系统→工具→记忆→RAG→用户
}   // 同会话轮次间前缀不变 → KV/Prompt Cache 复用(推理侧)

public Mono<String> ask(String input) {
    return semanticCache.hit(input)                     // ①语义缓存:相似问复用答案
        .switchIfEmpty(retrievalCache.andAssemble(input) // ②检索缓存:query复用
            .map(ctx -> llm.call(ctx)));                 // ③KV缓存:前缀复用(推理服务)
}
```

## 三、失效纪律

| 缓存 | 失效触发 |
|------|---------|
| 语义 | 高风险场景禁用 + TTL + 人工反馈负相关时清 |
| 检索 | 知识库版本变更（血缘联动） |
| KV 前缀 | 层内容变化（系统提示改版/工具集变） |

## 四、验收

| 测试 | 期望 |
|------|------|
| 同会话多轮 | 前缀稳定 KV 命中 |
| 相似问题 | 语义缓存命中省钱 |
| 知识更新 | 检索缓存失效 |
