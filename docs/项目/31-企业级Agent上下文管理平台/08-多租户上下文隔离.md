## 二、隔离三处

```java
// 概念代码：租户贯穿（Reactor Context）
public Mono<Assembled> assemble(String input) {
    return Mono.deferContextual(ctx -> {
        String tenant = ctx.get("tenant.id");          // 响应式上下文取租户(WebFlux铁律)
        var mem = memory.recall(tenantScoped(tenant), input);      // ①供给隔离
        var rag = retrieval.search(tenantScoped(tenant), input);
        var cached = semanticCache.get(key(tenant, input));        // ②缓存分键
        return render(policy.of(tenant), mem, rag, input);        // ③租户策略
    });
}
```

### 二.1 本节测试与验证（多租户隔离）

**前置条件**：`tenantScoped/tenant/tenantScoped(tenant)/key(tenant,...)/policy.of(tenant)` 均已实现；Reactor Context 传租户（WebFlux 铁律）。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 租户 A 装配 | 记忆/文档检索仅含 A 数据，B 条目召回为 0 |
| 2 | 商户 B 复用 A 的检索输入 | 缓存只命中 B 自己的键，未命中 A 的缓存（键含租户） |
| 3 | VIP 租户装配 | 大配额策略生效（配额高于免费租户） |
| 4 | 免费租户装配 | 小配额生效，未挤占共享资源 |
| 5 | 无租户上下文（缺失 `tenant.id`） | 装配拒绝或走默认租户，不明文混入任意租户数据 |

**失败排查**：①跨租户召回>0→`tenantScoped` 过滤未在供给层入口强制施加；②缓存串租户→`key()` 未拼 `tenant`；③VIP 不生效→`policy.of(tenant)` 找不到该租户策略映射。
