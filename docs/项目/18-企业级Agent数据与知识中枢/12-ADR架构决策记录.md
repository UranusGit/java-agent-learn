## 二、关键详解

### ADR 18-00：带契约资产

- **备选**：①先入库后补元数据 ②无契约不入库。
- **决策**：②——事后补契约永远补不全；无主/无血缘的数据是不可信知识。
- **取舍**：接入门槛升高（源方需登记 owner/敏感级）；换可信。

### ADR 18-03：指标同名唯一

- **备选**：①允许同名多口径（调用方指定）②全局唯一。
- **决策**：②——多口径=每个 Agent 各答各数；冲突走指标评审而非并存。
- **可回滚**：DEPRECATED 状态保留历史（不物理删）。

### ADR 18-07：supersededBy 而非删除

- **备选**：①新事实覆盖/删除旧 ②链式取代。
- **决策**：②——历史可溯（审计）、Agent 可声明"以新为准"、回滚=断链。
- **呼应**：PagerDuty 2026 共识"共享事实失效是 RAG 最大坑"的直接解法。
