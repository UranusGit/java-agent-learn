# 05-身份互信与最小授权

> **定位**：协作安全的根基——**① 跨域身份互信（可验证身份，OIDC/JWT 或 SVID）② 最小授权裁决（委托不放大）③ 权限策略与拒绝审计**。呼应 [教程 54 §4](../../教程/54-Agent间协作协议工程化.md)、[31-安全](../../教程/31-安全与权限控制.md)、[16-网格零信任](../../项目/16-企业级Agent服务网格/04-身份零信任与mTLS.md)。前置阅读：[04-委托执行与进度取消](04-委托执行与进度取消.md)。
>
> **铁律 0**：身份/授权引擎自研「概念代码」（JWT/OIDC 为业界标准库，标注需引入依赖后实证）。

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①委托请求强制携带可验证身份凭证 ②授权裁决器（原始授权 ∩ 目标能力，不放大）③越权拒绝 + 审计 |
| **影响了哪些模块** | CollabMediator 入口 → 身份校验前置；新增 AuthorizationPDP |
| **架构如何演进** | 从"匿名协作"演进为"身份互信 + 权限裁决" |
| **上一版痛点** | 任何 Agent 可委托任何能力；用户授权被转委托放大 |

**本迭代验收**：①无凭证/伪造凭证请求被拒 ②"委托不放大"：转委托权限 ⊆ 原始授权 ∩ 目标能力 ③越权尝试 100% 拒绝 + 审计。

## 二、身份互信（谁在委托）

```java
// 概念代码：跨域身份验证（JWT 签名验证 / SVID 校验）
public Identity verify(AuthCredential cred) {
    return switch (cred) {
        case JwtCredential j -> jwtVerifier.verify(j.token());   // OIDC/JWT(需引入依赖后实证)
        case SvidCredential s -> spiffe.verify(s.x509());        // SPIFFE/SVID(呼应16网格)
        default -> throw new Unauthorized("credential required");
    };
}
// 所有协作 API 前置：无有效身份 = 拒绝（Fail-closed）
```

## 三、最小授权（委托不放大）

```java
// 概念代码：授权裁决（交集语义）
public Set<String> adjudicate(DelegationRequest req, Identity caller) {
    Set<String> granted = caller.permissions();          // 原始授权(来自用户/平台)
    Set<String> wanted  = Set.of(req.capability());
    if (!granted.containsAll(wanted))
        throw new Forbidden("委托超出原始授权: " + diff(granted, wanted));   // 不放大
    return wanted;                                        // 最小集放行
}
```

**规则**：`放行权限 = 原始授权 ∩ 目标能力`——委托方**不能把自己没有的能力转委托出去**，也**不能要求超出用户授权的 scope**（呼应 [16-网格"委托不放大"](../../项目/16-企业级Agent服务网格/10-A2A互操作与策略市场.md)、[08-零信任 PDP](../../项目/08-Agent供应链安全网关/06-零信任策略引擎.md)）。

## 四、拒绝审计

所有 Forbidden/Unauthorized 落审计（who/target/capability/ts）——既是安全回溯证据，也是异常行为（高频越权尝试）告警的数据源（呼应 [23-审计](../../教程/23-工具执行可观测与审计.md)）。

## 五、验收

| 测试 | 期望 |
|------|------|
| 无凭证委托 | 401 拒绝 |
| 委托方没有的能力 | 403 拒绝 + 审计 |
| 转委托放大 | 被交集裁决拦下 |
| 正常最小授权 | 放行且记录 |
