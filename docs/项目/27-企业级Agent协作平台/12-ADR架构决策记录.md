## ADR-01：A2A 适配层自研

**决策**：AgentCard/委托协议自研「概念代码」，基座 MCP 2.0 SDK + ChatClient。

**背景**：A2A 为开放协议，本机无官方 Java SDK（实证 find a2a 空）；与项目16 网格结论一致。

**取舍**：自研可控可观测；待官方 Java SDK 成熟可替换适配层（协议语义不变）。

### ADR-01.1 本节核对

- [ ] 决策/背景/取舍三要素齐全，且与 02 迭代「概念代码」自研路线一致
- [ ] 与 21 网格 ADR-01 结论不矛盾（均"无官方 SDK→自研适配层"）

## ADR-02：注册中心 + 心跳被动下线

**决策**：Agent 定期心跳，超时 OFFLINE 摘除；Card 版本化。

**背景**：Agent 崩溃不会发注销；能力变更高频。

**取舍**：被动下线可靠；版本化带来存储开销（换可追溯）。

### ADR-02.1 本节核对

- [ ] 与 02 迭代 `sweepOffline()` 心跳超时摘除实现一致
- [ ] 版本化取舍（存储开销换可追溯）如实记录，未隐藏成本

## ADR-03：两级能力发现

**决策**：精确 capability 命中优先，语义（embedding 相似）兜底。

**背景**：能力名不统一（"出报表"↔"生成经营报告"）。

**取舍**：确定性先行零成本，语义承接长尾（与 23 意图路由同方法论）。

### ADR-03.1 本节核对

- [ ] 精确优先→语义兜底两路与 02 迭代 `discover` 一致
- [ ] "精确命中即短路"语义（低成本）已在 02 验证可测量

## ADR-04：委托两阶段（先协商后执行）

**决策**：协商（能力/报价/时长）通过才提交异步任务。

**背景**：同步调用长任务必超时；事后才知道超预算。

**取舍**：多一次协商往返（换"事前合同"——预算/时长确定性）。

### ADR-04.1 本节核对

- [ ] 协商→异步两阶段与 03 迭代 `negotiate/delegate` 一致
- [ ] 取舍（往返延迟换预算/时长确定性）在 03 测试中被覆盖

## ADR-05：委托不放大（交集裁决）

**决策**：放行权限 = 原始授权 ∩ 目标能力；禁止转委托未授权能力。

**背景**：协作链上的权限放大是最大安全面（呼应 16 网格同结论）。

**取舍**：安全 >> 灵活；需要授权的用户显式加 scope。

### ADR-05.1 本节核对

- [ ] 交集裁决（`放行 = 原始授权 ∩ 目标能力`）与 05 迭代 `adjudicate` 一致
- [ ] "委托不放大"在 05 测试中 100% 拒绝越权验证（对照 00 验收②）

## ADR-06：跨域返回以数据边界进入上下文

**决策**：返回内容一律隔离标记包裹 + 注入检测，不进系统提示。

**背景**：间接注入（对方返回藏指令）是 A2A 特有攻击面。

**取舍**：严格边界（少量信息损失）>> 被反向操控风险。

### ADR-06.1 本节核对

- [ ] 隔离标记包裹 + 注入检测与 06 迭代 `sandboxResult` 一致
- [ ] "边界内是数据、非指令"约束在 06 测试中被验证（注入 100% 拦）

## ADR-07：失败分类降级链 + 不可逆转人工

**决策**：瞬时重试→换Agent→带因重委托→本地兜底→人工；不可逆副作用禁自动补偿。

**背景**：协作跨网络跨系统失败必然发生；支付/外发误补偿更糟。

**取舍**：宁升人工不误补偿（呼应 24/28 的 HITL 纪律）。

### ADR-07.1 本节核对

- [ ] 降级链（瞬时重试→换Agent→带因重委托→本地兜底→人工）与 07 迭代 `resilientDelegate` 一致
- [ ] 不可逆副作用禁自动补偿在 07 测试中被验证（payment.* 升人工）

## ADR-08：外域低信任默认 + 严约束

**决策**：EXTERNAL 信任级默认低信任：高风险强制 HITL、严限额、深校验。

**背景**：跨组织信任无法与内部等价；默认必须保守。

**取舍**：跨域"贵"（审批/限额成本）成为显式决策，而非默认放开。

### ADR-08.1 本节核对

- [ ] EXTERNAL 低信任（强制 HITL/严限额/深校验）与 09 迭代加强策略一致
- [ ] "跨域贵"为显式成本决策而非默认放开，与 ADR 文字口径一致
