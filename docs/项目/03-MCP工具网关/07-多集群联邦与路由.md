# 07-多集群联邦与路由——跨集群目录同步 + 就近接入

> **定位**：把单一网关扩展为**多集群联邦**：跨集群工具目录同步（最终一致）、就近路由（区域工具副本/延迟感知）、联邦鉴权（跨集群 token 委托不放大权限）、全局目录一致性（冲突消解）。读者画像：工具规模/地域规模超出单集群，需要联邦化的读者。前置阅读：[06-工具市场与计费](06-工具市场与计费.md)。
>
> **铁律 0**：联邦机制为自研业务；MCP 调用签名与基准 §11 一致。

## 三、目录同步

### 3.1 同步模型（最终一致 + 版本向量）

```java
package com.example.mcp.gateway.federation;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import lombok.extern.slf4j.Slf4j;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.List;
import java.util.Map;

/** 目录同步——增量拉取兄弟集群的目录变更，本地合并。 */
@Slf4j
@Component
public class CatalogSyncService {

    private final JdbcTemplate jdbc;
    private final ObjectMapper objectMapper;
    private final HttpClient http = HttpClient.newBuilder()
            .connectTimeout(Duration.ofSeconds(5)).build();
    private final List<String> peers;   // 兄弟网关地址（配置注入）

    public CatalogSyncService(JdbcTemplate jdbc, ObjectMapper objectMapper, List<String> peers) {
        this.jdbc = jdbc;
        this.objectMapper = objectMapper;
        this.peers = peers;
    }

    /** 兄弟网关目录条目（目录快照最小结构，字段与 federation_tool_catalog 对齐）。 */
    public record CatalogEntry(String name, String admissionStatus, long version, String fingerprint) {}

    @Scheduled(fixedDelay = 30_000)     // 30s 最终一致
    public void sync() {
        for (String peer : peers) {
            try {
                // ① 拉取 peer 的目录增量（version > 本地已知该 peer 的水位）
                //    兄弟网关由同款服务暴露目录快照端点 GET {peer}/federation/catalog?since=…
                long since = watermark(peer);
                List<CatalogEntry> delta = fetchDelta(peer, since);

                // ② 冲突消解（规则见 §3.2）③ 合入本地联邦目录表 federation_tool_catalog
                for (CatalogEntry entry : delta) {
                    merge(peer, entry);
                }

                // 拉取成功才推进水位；失败不推进 → 下次调度重拉（最终一致自愈）
                delta.stream().mapToLong(CatalogEntry::version)
                        .max().ifPresent(v -> advanceWatermark(peer, v));
            } catch (Exception e) {
                // 单 peer 失败不影响其他 peer；水位不推进，下次调度重试
                log.warn("从 {} 同步目录失败: {}", peer, e.getMessage());
            }
        }
    }

    /** 本地水位 = 已应用该 peer 的最大版本号。水位表 federation_sync_watermark(peer text PK, watermark bigint)。 */
    private long watermark(String peer) {
        List<Long> rows = jdbc.query(
                "SELECT watermark FROM federation_sync_watermark WHERE peer = ?",
                (rs, i) -> rs.getLong(1), peer);
        return rows.isEmpty() ? 0L : rows.get(0);
    }

    /** 推进水位（只增不回退）。 */
    private void advanceWatermark(String peer, long version) {
        jdbc.update("""
                INSERT INTO federation_sync_watermark (peer, watermark) VALUES (?, ?)
                ON CONFLICT (peer) DO UPDATE SET watermark = GREATEST(watermark, EXCLUDED.watermark)
                """, peer, version);
    }

    /** 拉取兄弟网关目录增量：GET {peer}/federation/catalog?since={水位}，返回 JSON 数组。 */
    private List<CatalogEntry> fetchDelta(String peer, long since) throws Exception {
        String url = peer + "/federation/catalog?since=" + since;
        HttpRequest req = HttpRequest.newBuilder(URI.create(url))
                .timeout(Duration.ofSeconds(10)).GET().build();
        String body = http.send(req, HttpResponse.BodyHandlers.ofString()).body();
        return objectMapper.readValue(body, new TypeReference<List<CatalogEntry>>() {});
    }

    /**
     * 按 §3.2 规则冲突消解后合入本地目录表：
     * federation_tool_catalog(tool_name text PK, admission_status text, version bigint,
     *                         fingerprint text, owner_peer text, updated_at timestamptz)。
     */
    private void merge(String peer, CatalogEntry entry) {
        Map<String, Object> local = findLocal(entry.name());
        if (local == null) {                                   // 本地没有 → 直接合入
            upsert(peer, entry);
            return;
        }
        String localStatus = (String) local.get("admission_status");
        long localVersion = ((Number) local.get("version")).longValue();
        String localFp = (String) local.get("fingerprint");

        // 规则 1：准入状态优先——PUBLISHED 侧权威，忽略对端下架/审查
        if ("PUBLISHED".equals(localStatus) && !"PUBLISHED".equals(entry.admissionStatus())) {
            return;
        }
        if (!"PUBLISHED".equals(localStatus) && "PUBLISHED".equals(entry.admissionStatus())) {
            upsert(peer, entry);
            return;
        }
        // 规则 2：均 PUBLISHED → 高版本胜
        if (entry.version() > localVersion) {
            upsert(peer, entry);
            return;
        }
        if (entry.version() < localVersion) {
            return;
        }
        // 规则 3：版本不可比（此处版本为数值，不可比即指纹不一致）→ 指纹一致则任一；不一致进人工仲裁
        if (!localFp.equals(entry.fingerprint())) {
            log.warn("工具 {} 需要人工仲裁: 本地指纹 {} vs 对端指纹 {}", entry.name(), localFp, entry.fingerprint());
            jdbc.update("UPDATE federation_tool_catalog SET admission_status = 'ARBITRATION' WHERE tool_name = ?",
                    entry.name());
        }
        // 指纹一致 → 幂等跳过（双活副本，保留本地记录）
    }

    private Map<String, Object> findLocal(String name) {
        List<Map<String, Object>> rows = jdbc.queryForList(
                "SELECT admission_status, version, fingerprint FROM federation_tool_catalog WHERE tool_name = ?",
                name);
        return rows.isEmpty() ? null : rows.get(0);
    }

    /** upsert 合入（owner_peer 记录来源，供对账/审计）。 */
    private void upsert(String peer, CatalogEntry entry) {
        jdbc.update("""
                INSERT INTO federation_tool_catalog
                    (tool_name, admission_status, version, fingerprint, owner_peer, updated_at)
                VALUES (?, ?, ?, ?, ?, now())
                ON CONFLICT (tool_name) DO UPDATE SET
                    admission_status = EXCLUDED.admission_status,
                    version = EXCLUDED.version,
                    fingerprint = EXCLUDED.fingerprint,
                    owner_peer = EXCLUDED.owner_peer,
                    updated_at = now()
                """, entry.name(), entry.admissionStatus(), entry.version(),
                entry.fingerprint(), peer);
    }
}
```

### 3.3 本节测试与验证（同步时序与冲突消解）

**前置条件**：两套网关（A/B）可互访；`federation_tool_catalog` 表已建；`peers` 配置互指。

**材料——同步剧本**：

```bash
# A 集群登记新工具（或直接 INSERT 目录表）
# B 集群观察同步结果
watch -n 5 'curl -s http://gateway-b:8081/tools | jq ".[].name" | grep newTool'
```

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | A 登记新工具后观察 B | ≤30s 内 B 的 discover 可见（验收①） |
| 2 | A 下架该工具 | ≤30s 内 B 同步移除 |
| 3 | 冲突场景 1：同名工具 A 侧 PUBLISHED、B 侧 DELISTED | 以 PUBLISHED 侧为准 |
| 4 | 冲突场景 2：两侧均 PUBLISHED 且版本可比 | 高版本胜 |
| 5 | 冲突场景 3：版本不可比 + 指纹不同 | 进人工仲裁，且审计表留痕 |
| 6 | 断开 A↔B 网络 5 分钟再恢复 | 增量水位续传，目录收敛一致（最终一致可自愈） |

**失败排查**：①30s 不可见→`@Scheduled` 未启用（启动类 `@EnableScheduling`）或 peers 地址配错；②冲突双写→消解规则顺序错误（先查准入状态再比版本）；③恢复后目录重复→水位未真正持久化（`federation_sync_watermark` 表未建 / 只在拉取成功后推进的兜底被跳过，导致每次全量合并未去重）。

## 四、就近路由

```java
package com.example.mcp.gateway.federation;

import org.springframework.stereotype.Component;
import java.util.List;

/** 就近路由——本地副本优先，跨区仅在没有本地副本或本地不可用时。 */
@Component
public class ProximityRouter {

    public Route decide(String toolName, List<Replica> replicas) {
        // ① 本集群副本健康 → 直接路由
        Replica local = replicas.stream()
                .filter(Replica::local)
                .filter(Replica::healthy)
                .findFirst().orElse(null);
        if (local != null) return new Route(local, false);

        // ② 无本地副本 → 选延迟最低的远端副本（滑动窗口 P50）
        return replicas.stream()
                .filter(Replica::healthy)
                .min(java.util.Comparator.comparingDouble(Replica::p50LatencyMs))
                .map(r -> new Route(r, true))
                .orElseThrow(() -> new IllegalStateException("无可用副本: " + toolName));
    }

    public record Replica(String cluster, String endpoint, boolean local,
                          boolean healthy, double p50LatencyMs) {}
    public record Route(Replica replica, boolean crossCluster) {}
}
```

**延迟探测**：复用既有健康检查（心跳 + 采样调用），P50 滑动窗口 5 分钟。

### 4.1 本节测试与验证（就近路由决策）

**前置条件**：同名工具在 A/B 均有副本；延迟探测已有采样数据。

**执行方式**：`mvn test -Dtest=ProximityRouterTest` 驱动断言 6；延迟对比（断言 3）用 `curl -w '%{time_total}'` 对两个远端副本各发一次调用对比耗时。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 本地副本健康时调 100 次 | `crossCluster=false` 占 100%（本地优先） |
| 2 | 摘除本地副本（复用 02 篇故障注入） | 自动切换远端（`crossCluster=true`），无 5xx |
| 3 | 两个远端副本延迟不同（人为加 50ms） | 路由到 P50 更低者（延迟感知） |
| 4 | 本地副本恢复 | 回切本地（自动回切） |
| 5 | 全部副本不健康 | 抛 `IllegalStateException`（无可用副本语义明确） |
| 6 | `ProximityRouterTest`：本地 unhealthy + 远端 healthy | 选远端——`filter(Replica::local)` 先于 `healthy` 的顺序不误选病副本 |

**失败排查**：①跨区比例异常→`Replica.local` 标记错误；②选了高延迟副本→P50 窗口未更新（核 5 分钟滑动窗口）；③恢复不回切→决策无重算或缓存了旧 Route。

## 五、联邦鉴权（委托不放大）

```mermaid
sequenceDiagram
    participant A as Agent(区域A)
    participant GA as 网关A
    participant GB as 网关B
    participant T as 工具(order@B)

    A->>GA: 调用 order 工具(带 tenant JWT)
    GA->>GA: 本地无副本 → 跨区转发
    GA->>GB: 联邦转发 token(scope=federation:order:call, 租户claim, TTL 30s)
    GB->>GB: 验签 + 权限⊆检查(单工具单次, 不可再委托)
    GB->>T: 执行
    T-->>GB: 结果
    GB-->>GA: 返回(全链路审计含双方集群ID)
```

**关键纪律**：联邦 token 是**短 TTL（30s）+ 单工具 + 单次调用**的最小授权——区域 B 不能用它做任何其他事，也不能再委托（防权限链式放大）。

### 5.1 本节测试与验证（委托不放大）

**前置条件**：跨区转发链路可用（§4.1 场景 2 已触发过转发）；区域 B 可观测审计日志。

**执行方式**：`mvn test -Dtest=FederationAuthTest` 驱动单工具/TTL 断言；重放与再委托（断言 2/3/4）用 curl 跨区调用复现并观察区域 B 拒绝响应与审计留痕。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 正常跨区调用（本地无副本） | 成功；双方集群审计均落记录（含双方集群 ID） |
| 2 | 用同一联邦 token 尝试调第二个工具 | 拒绝（单工具约束） |
| 3 | 用该 token 再委托第三个集群 | 拒绝（不可再委托） |
| 4 | 30s 后重放该 token | 拒绝（TTL 过期） |
| 5 | 联邦 token 的 scope 与原始租户权限比对 | scope ⊆ 原始权限（不放大） |
| 6 | 时序图六步逐条核对 | 验签→权限⊆检查→执行→审计的顺序与实现一致 |

**失败排查**：①token 可调第二个工具→scope 未绑定单工具（应在委托时写死 `federation:<tool>:call`）；②可再委托→B 侧未禁止二次签发；③重放成功→TTL 校验缺失或时钟偏差过大（校验留 ±5s 时钟余量）。
