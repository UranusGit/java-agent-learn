## 二、保语义脱敏管线

```mermaid
flowchart LR
    RAW["原始事件<br/>含 PII"] --> DET["实体检测<br/>NER/规则双重"]
    DET --> MAP{"替换映射"}
    MAP -->|"人名"| P1["假人名池<br/>(同映射全库一致)"]
    MAP -->|"卡号/手机"| P2["类型合法假值<br/>Luhn/号段"]
    MAP -->|"日期"| P3["等偏移平移<br/>(时间结构不变)"]
    P1 & P2 & P3 --> OUT["脱敏事件"]
    OUT --> AUD["抽检队列<br/>(人审 0 残留放行)"]
    style MAP fill:#fff9c4
    style AUD fill:#c8e6c9
```

**一致性映射是关键**：同一真实实体全库映射到同一假名（张三→李四处处一致）——否则多轮会话中"前后指同一个人"的推理被破坏，回放行为变形，仿真结论失真。

### 二.1 本节测试与验证（保语义脱敏管线）

**前置条件**：采集管道（Observation 镜像）+NER/正则双检脱敏实现。

**材料 A——PII 样本**（20 条）：`张三的手机 13800138000，卡号 6222020200112233，生日 1990-01-01` 类。

**材料 B——分布统计**：脱敏前后各算输入长度直方图+意图占比，KS 检验。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 材料A 过管道+人审 | 0 PII 残留；同一实体全库同一假名（映射一致） |
| 2 | 材料B 前后对比 | 长度/意图分布 KS p>0.05（不变形） |

**失败排查**：①一人两假名→映射无全局缓存；②变形→日期未等偏移平移。

## 三、回放集版本化（资产纪律）

| 要素 | 规则 |
|------|------|
| 版本 | `R<vN>`，只增不改；每版带采集窗口/采样 seed/场景标签 |
| 指纹 | 流量分布摘要哈希（输入长度分桶/意图类别占比/工具调用频次）——指纹稳定=分布稳定 |
| 只读 | 版本库挂只读锁；仿真产出一律写新报告，禁止回写数据集 |
| 复现 | 任何历史报告可注明"基于 R7"——结论永远可复现 |

### 三.1 本节测试与验证（回放集版本化/资产纪律）

**前置条件**：版本库挂只读锁；采集支持固定采样 seed。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 同 seed 采两版 | 流量分布摘要哈希一致（指纹稳定） |
| 2 | 脚本尝试回写 R7 | 被拒+告警（版本只读） |
| 3 | R7 重跑 01 对比 | 与历史报告一致（可复现） |

**失败排查**：①指纹不稳定→seed 未固定或采集无序随机抽取；②回写未拒→版本库连了可写连接。

## 四、全篇回归验证

> §二.1（脱敏管线）与 §三.1（版本化纪律）均通过后的整体验收。

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 抽检 1000 例过管道后人审 | 0 PII 残留（双检人审放行） |
| 2 | 完整跑一遍采集→脱敏→版本化 | 分布保真（KS 通过）+指纹稳定+回写被拒+可复现同时成立 |
| 3 | 核对 90 天滚动窗口 | 过期窗口内数据被清理或重新采集（生命周期生效） |

**失败排查**：任一步 FAIL 按 §二.1/§三.1 失败排查项回溯（映射缓存 / 日期偏移 / seed / 只读连接）。

## 五、本迭代痛点

流量干净了，但回放仍打真实 LLM/工具——成本与副作用没解决；依赖行为还会漂移（供应商改接口）。→ 03 孪生环境与依赖替身。

> 本节核对（一句话）：两条痛点（回放仍打真实 LLM/工具→成本副作用未消；依赖行为漂移→供应商改接口）与 03 孪生环境与依赖替身一一对应，无搁置项即 PASS。
