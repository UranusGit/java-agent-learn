## 二、关键详解

### ADR 21-00：变量唯一

- **备选**：①孪生直连真实依赖（更"真"）②全依赖替身。
- **决策**：②——直连则供应商漂移污染变更结论，成本与副作用不可控；逼真度问题用持续校准（21-10）解决而不是靠直连。
- **代价**：替身开发与运营成本；失真风险（由 10 兜底）。

### ADR 21-04：两档 LLM 替身

- **备选**：①全真实 LLM ②全录制回放 ③分档。
- **决策**：③——效果类变更必须真模型（回放的历史输出测不出新 Prompt 效果）；编排/故障/容量类变更模型非变量，录制回放零成本且行为钉住。
- **代价**：档位选择需要变更分类纪律（07 风险分级承接）。

### ADR 21-08：闸门硬约束+豁免成本

- **备选**：①仿真报告供参考（软约束）②流水线硬拒绝+豁免双签公示。
- **决策**：②——软约束必然被赶工绕过（发布压力永远赢过质量流程）；豁免留口但成本高（双签+公示），让例外少而可见。
- **回滚**：保留风险分级快速通道即可退化回软约束。

### ADR 21-10：失真红牌收紧闸门

- **备选**：①失真时暂停仿真平台 ②收紧闸门+触发再校准。
- **决策**：②——孪生失真时仿真仍有保守参考价值；停平台反而让变更裸奔。红牌期多变更多跑，绿牌后恢复分级。
