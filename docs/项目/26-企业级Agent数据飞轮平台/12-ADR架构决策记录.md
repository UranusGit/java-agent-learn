## ADR-01：四环齿轮组平台

**决策**：飞轮按 采集→评估→优化→灰度 四环建设，任一环断即整体停转。

**背景**：只攒数据不改、只改不验证都是"假飞轮"。

**取舍**：平台复杂度高，换"改进闭环确定性"（每环可度量可治理）。

## ADR-02：血缘五层强制

**决策**：agent/prompt/kb/rule/model 五层版本坐标强制；缺血缘数据降级只读不进优化环。

**背景**：无归因的差例修复是盲打；kb 更新引入的回归改 Prompt 无效。

**取舍**：采集端多一次快照（成本低），换归因能力（价值高）。

## ADR-03：门禁双卡

**决策**：改进项必须"目标差例修复 + 金标不回归"双卡通过。

**背景**：只看修复不看回归=按下葫芦浮起瓢。

**取舍**：门禁耗时（离线评估跑批），换回归拦截（00 验收③）。

## ADR-04：归因分型定向修复

**决策**：差例先归因（KB_GAP/PROMPT_FLAW/RULE_HIT/MODEL_LIMIT）再出对应层修复。

**背景**：知识缺失改 Prompt 白费；模型边界硬补规则误伤。

**取舍**：归因有误差（抽样≥80%），人审兜底。

## ADR-05：灰度三指标守门

**决策**：差例率/满意度/成本三指标任一恶化自动回滚。

**背景**：改进上线是变更风险；均值掩盖恶化。

**取舍**：观测窗口拉长周期，换上线确定性。

## ADR-06：免疫前置

**决策**：来源分级/交叉验证/异常冻结在采集入口执行，而非事后清洗。

**背景**：污染入湖后清洗成本高且难彻底。

**取舍**：入口延迟略增，换污染拦截（≥95%）。

## ADR-07：联邦不混池

**决策**：业务数据命名空间隔离永不共享；仅脱敏通用模式共享。

**背景**：业务敏感（合规）；但攻击样本等通用模式重复发现浪费。

**取舍**：共享层薄（只模式），换合规安全+复利。

## ADR-08：主动加速

**决策**：定向探针主动找问题 + 高风险修复仿真前置。

**背景**：被动等差例周期长；高风险改进直接灰度风险大。

**取舍**：探针消耗 Token 成本，按价值定向（只探低置信/边缘）。

## 决策代价回顾

- ADR-01 平台化 = 建设成本（对单业务可先走 41 单环再升）。
- ADR-03 门禁 = 评估算力（跑批成本）。
- ADR-08 探针 = Token 开销（定向控制）。
