## 二、四源接入与清洗

```java
// 概念代码：多源采集管道
public Mono<String> ingest(FlywheelSource src, RawItem raw) {
    return Mono.fromCallable(() -> {
        var cleaned = cleaner.clean(raw);                    // 去噪/脱敏(呼应25合规)
        if (dedup.isDuplicate(cleaned)) return dupId(cleaned); // 语义去重(实证 embed 相似)
        var labeled = annotator.label(cleaned);              // LLM 初判+置信
        if (labeled.confidence() < HUMAN_REVIEW_MIN)
            reviewQueue.offer(labeled);                      // 低置信进人审
        return lake.save(labeled.withTrust(trustOf(src)));   // 来源分级: AUTH>ANON>EXTERNAL
    });
}
```

## 三、差例自动检出（最重要的源）

手工反馈永远稀疏——**自动差例检出**是飞轮主油路：

| 检出信号 | 来源 |
|---------|------|
| 用户明确负反馈（踩/重问/弃用） | 前端埋点 |
| 拒答/循环/超时 | 运行时事件（Observation） |
| 复核驳回（HITL） | 复核工作台（30-10） |
| 在线哨兵低分 | 19-04 式哨兵 |
