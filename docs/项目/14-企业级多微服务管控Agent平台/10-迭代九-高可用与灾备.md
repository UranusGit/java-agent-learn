| 问 | 答 |

| 服务 | 单实例吞吐 | 目标 QPS | 实例数 |

### 4.2 HPA 配置（K8s）

```yaml

kind: HorizontalPodAutoscaler
metadata:
  name: agent-executor-hpa

  scaleTargetRef:
    apiVersion: apps/v1

  minReplicas: 2
  maxReplicas: 20
  metrics:
    - type: Resource

        name: cpu
        target:
```

## 六、优雅停机与滚动发布

```mermaid
sequenceDiagram
    participant K as K8s
    participant P as Pod(旧)
    participant P2 as Pod(新)

    K->>P: SIGTERM（滚动发布开始）
    P->>P: 停止接收新请求(就绪探针变 false)
    P->>P: 处理完在途请求(优雅停机窗口)
    K->>P2: 启动新 Pod(就绪后接流量)
    P2-->>K: 就绪
    Note over P,P2: 零停机发布
```

```yaml
# spring boot 优雅停机
server:
  shutdown: graceful
spring:
  lifecycle:
    timeout-per-shutdown-phase: 30s
```
