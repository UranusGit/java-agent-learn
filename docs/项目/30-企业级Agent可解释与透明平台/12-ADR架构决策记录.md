## ADR-01：系统层 XAI

**决策**：可解释聚焦"证据链/轨迹/置信"（系统层），不解释模型内部权重。

**背景**：LLM 黑盒内部解释是模型层研究领域；业务要的是"依据什么、经历什么、多大把握"。

**取舍**：系统层可工程化、可校验、满足合规；模型层留前沿（13）。

### ADR-01 本节核对（系统层 XAI）

- [ ] 决策（聚焦证据链/轨迹/置信，不解释模型内部权重）的取舍理由（系统层可工程化/可校验/合规 vs 模型层留前沿）能复述
- [ ] 与 00 的"四层架构"与 13 前沿的模型层跟踪定位一致，无越界当实

## ADR-02：解释三层视图

**决策**：概要（用户）/标准（排障）/取证（监管）三级，按受众路由。

**背景**：单一详略要么泄露内部细节、要么不够取证。

**取舍**：多一层渲染复杂度，换隐私/可用/合规三者兼得。

### ADR-02 本节核对（解释三层视图）

- [ ] 决策（概要/标准/取证三级按受众路由）与 02 迭代的三种受众（用户/排障/监管）一一对应，无遗漏
- [ ] 取舍（多一层渲染换隐私/可用/合规三者兼得）有明确买单方（渲染/存储成本），非只讲好处

## ADR-03：归因抽取 + 结论分型

**决策**：结构化抽取结论与证据引用；结论标 FACT/RULE_HIT/INFERENCE。

**背景**：整段回答无法归因；伪装全部"有据"是伪解释。

**取舍**：强制诚实分型——INFERENCE 显式标注优于伪装。

### ADR-03 本节核对（归因抽取 + 结论分型）

- [ ] 决策（结构化抽取 + FACT/RULE_HIT/INFERENCE 分型）与 03 迭代的三种 kind 含义一致
- [ ] 取舍（INFERENCE 显式标注优于伪装有据）与 03「三结论分型」纪律口径一致，非"全部伪装有据"

## ADR-04：归因两级校验

**决策**：存在性（EV-id 真实存在，确定性）+ 相关性（相似度）校验；高风险伪归因拒绝发布。

**背景**：模型会编造引用；伪解释比无解释更危险。

**取舍**：校验成本（一次 embed/条）换解释可信。

### ADR-04 本节核对（归因两级校验）

- [ ] 决策（存在性 + 相关性两级校验，高风险伪归因拒绝发布）与 04 迭代的两级管线一致
- [ ] 取舍（一次 embed/条成本换解释可信）有明确代价买单（校验的一次 embed 开销），非零成本空许诺

## ADR-05：置信分来源 + 校准

**决策**：置信按结论来源（规则/证据/推测）计算，并用实际正确率分桶校准，失准桶降级。

**背景**：未校准置信是伪信任（自报 0.9 实际 0.6）。

**取舍**：校准需要历史样本（冷启动期用保守默认）。

### ADR-05 本节核对（置信分来源 + 校准）

- [ ] 决策（按来源计算置信 + 用实际正确率分桶校准、失准桶降级）与 05 迭代的置信来源 switch 与校准流程一致
- [ ] 取舍（校准需历史样本、冷启动保守）有明确缓解（保守默认），呼应 05 失准桶治理

## ADR-06：解释快照固化

**决策**：执行完成即固化解释快照，后续查询永远返回当时状态。

**背景**：证据源/记忆会更新衰减，但历史决策的解释必须还原决策时点。

**取舍**：存储成本（快照不可变）换合规追溯确定性（呼应 13 事件溯源思想）。

### ADR-06 本节核对（解释快照固化）

- [ ] 决策（执行完成即固化快照，后续查询返回当时状态）与 06 迭代「快照只读固化」一致
- [ ] 取舍（不可变存储增长换合规追溯确定性）有明确缓解（按保留期归档），呼应决策代价回顾 ADR-06 行

## ADR-07：反事实区分精确/近似

**决策**：规则项给确定阈值差；模型项扰动近似并强制"近似、不构成承诺"声明；仅高风险提供。

**背景**：模型反事实本质是估计；滥用会误导用户。

**取舍**：诚实声明 + 成本控制（按需生成缓存）。

### ADR-07 本节核对（反事实区分精确/近似）

- [ ] 决策（规则项确定阈值差 / 模型项扰动近似并强制"近似、不构成承诺"声明 / 仅高风险提供）与 07 迭代 §二/§三一致
- [ ] 取舍（诚实声明 + 按需生成缓存）明确区分确定与近似，且与 07「只对高风险按需生成」纪律衔接

## ADR-08：披露走审批 + hash 链

**决策**：监管数据包导出须经范围审批、六要素齐、hash 链防篡改、全程留痕。

**背景**：披露本身是敏感数据外发；监管要求不可篡改。

**取舍**：流程摩擦换合规安全（承 20 hash 链实践）。

### ADR-08 本节核对（披露走审批 + hash 链）

- [ ] 决策（导出须经范围审批、六要素齐、hash 链防篡改、全程留痕）与 08 迭代 §二 record + §三 审批一致
- [ ] 取舍（流程摩擦换合规安全）承接 20 hash 链实践，代价（审批流程成本）明确
