# 07-反事实边界解释

> **定位**：回答解释中最难的问题——**"差多少会翻转"**。核心：**① 规则项反事实（阈值差，确定性可算）② 模型项近似反事实（关键因子扰动，仅高风险用）③ 反事实的诚实边界（不可计算就说不可计算）**。呼应 [教程 56 §6](../../教程/99-Agent可解释与透明工程.md)、[21-参数扫描](../../项目/21-企业级Agent仿真与数字孪生平台/04-场景引擎与参数扫描.md)。前置阅读：[06-解释API与查询服务](06-解释API与查询服务.md)。
>
> **铁律 0**：规则反事实确定性；模型近似反事实自研「概念代码」（成本高，限高风险决策）。

## 二、规则反事实（确定性）

```java
// 概念代码：规则阈值距离
public Counterfactual ruleCf(RuleDecision d, ApplicantContext ctx) {
    double gap = d.threshold() - ctx.valueOf(d.metric());        // 距阈值差
    return Counterfactual.exact(d.metric() + " 再 " + fmt(gap) + " 即翻转",
                                d.metric(), gap);                 // 确定，可承诺
}
```

### 二.1 本节测试与验证（规则反事实——确定性）

**前置条件**：`RuleDecision`（含 `threshold`/`metric`）与 `ApplicantContext`（可 `valueOf(metric)` 取值）可用；`Counterfactual.exact(...)` 构造可用。

**材料——代码内含的旋钮**：`gap = d.threshold() - ctx.valueOf(d.metric())`；`fmt(gap)` 格式化差值；`Counterfactual.exact(metric, gap)` 标记"确定，可承诺"。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 构造月流水阈值 ¥10k、当前 ¥8k 的规则拒贷 | `ruleCf` 返回确定阈值差"月流水再 ¥2k 即翻转"（`gap=2000` 正确） |
| 2 | 检查返回类型 | `Counterfactual.exact` 标记确定（可承诺），非近似 |
| 3 | 构造已达阈值（当前 ≥ 阈值）场景 | `gap ≤ 0`，不产生"再 X 即翻转"误导（语义正确） |
| 4 | 预审通过的决策请求反事实 | 明确"本决策已通过，无反事实翻转需说明"或"仅高风险提供"诚实处理 |

**失败排查**：①差值算错→`valueOf(d.metric())` 被 `metrics` 名误差或单位不一致；②已通过决策还返回"再 X 即翻转"→`gap` 符号未按 `threshold-value` 语义处理；③被当成近似→`Counterfactual.exact` 构造未显式用 exact，导致与 §三 近似混为一类。

## 三、模型近似反事实（高风险专用）

```mermaid
graph LR
    A["高风险模型决策"] --> B["关键因子扰动<br/>(收入±10%/负债±10%...)"]
    B --> C["观察决策翻转点"]
    C --> D["近似反事实:<br/>'负债率降至X%以下大概率通过'"]
    D --> E["标注'近似'+"<br/>"不构成承诺"]
```

**纪律**：模型反事实是**近似估计**，解释中必须带"近似、不构成承诺"声明——把确定性反事实（规则）与近似反事实（模型）**显式区分**，是解释诚实性的底线。成本考量：扰动需多次推理，**只对高风险决策按需生成并缓存**（呼应 21-参数扫描的批量思想）。

- [ ] 纪律一句能说清"近似、不构成承诺"声明 + "只对高风险按需生成并缓存"的成本控制，且与 §二 确定性反事实显式区分
