# 07-反事实边界解释

> **定位**：回答解释中最难的问题——**"差多少会翻转"**。核心：**① 规则项反事实（阈值差，确定性可算）② 模型项近似反事实（关键因子扰动，仅高风险用）③ 反事实的诚实边界（不可计算就说不可计算）**。呼应 [教程 56 §6](../../教程/56-Agent可解释与透明工程.md)、[21-参数扫描](../../项目/21-企业级Agent仿真与数字孪生平台/04-场景引擎与参数扫描.md)。前置阅读：[06-解释API与查询服务](06-解释API与查询服务.md)。
>
> **铁律 0**：规则反事实确定性；模型近似反事实自研「概念代码」（成本高，限高风险决策）。

---

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①规则反事实（决策规则的阈值距离）②关键因子扰动近似（对模型决策找最敏感因子与翻转点）③反事实的适用性声明（能算/近似/不可算） |
| **影响了哪些模块** | 新增 CounterfactualEngine；解释 API 增反事实端点 |
| **架构如何演进** | 解释从"正向证据"扩展到"反向边界" |
| **上一版痛点** | 用户问"差多少能过"答不上；HITL 复核缺翻转参考 |

**本迭代验收**：①规则决策给出确定阈值差（"月流水再高 ¥2k 即通过"）②高风险模型决策给出近似关键因子 ③不可计算场景诚实声明。

## 二、规则反事实（确定性）

```java
// 概念代码：规则阈值距离
public Counterfactual ruleCf(RuleDecision d, ApplicantContext ctx) {
    double gap = d.threshold() - ctx.valueOf(d.metric());        // 距阈值差
    return Counterfactual.exact(d.metric() + " 再 " + fmt(gap) + " 即翻转",
                                d.metric(), gap);                 // 确定，可承诺
}
```

## 三、模型近似反事实（高风险专用）

```mermaid
graph LR
    A["高风险模型决策"] --> B["关键因子扰动<br/>(收入±10%/负债±10%...)"]
    B --> C["观察决策翻转点"]
    C --> D["近似反事实:<br/>'负债率降至X%以下大概率通过'"]
    D --> E["标注'近似'+"<br/>"不构成承诺"]
```

**纪律**：模型反事实是**近似估计**，解释中必须带"近似、不构成承诺"声明——把确定性反事实（规则）与近似反事实（模型）**显式区分**，是解释诚实性的底线。成本考量：扰动需多次推理，**只对高风险决策按需生成并缓存**（呼应 21-参数扫描的批量思想）。

## 四、验收

| 测试 | 期望 |
|------|------|
| 规则拒贷 | 确定阈值差 |
| 高风险模型决策 | 近似关键因子+声明 |
| 普通决策请求反事实 | "仅高风险提供"诚实拒绝 |
