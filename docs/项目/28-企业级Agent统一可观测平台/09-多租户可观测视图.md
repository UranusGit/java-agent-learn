| 问 | 答 |
|----|----|

## 二、双视角

```mermaid
graph TB
    subgraph tenant["租户视角(自助)"]
        T1["本租户健康/SLO"]
        T2["本租户用量与配额"]
        T3["本租户会话查询"]
    end
    subgraph platform["平台运营视角"]
        P1["全量健康+TopN大户"]
        P2["配额治理联动(教程26)"]
        P3["差体验租户定位"]
    end
```

**价值**：租户自助（减少工单）+ 平台治理（大户/差体验双清单）——遥测标签（02 增补的 tenant.id）是这一切的地基。

### 二.1 本节测试与验证（双视角与租户隔离）

**前置条件**：02 管道已给所有 Span 增补 `tenant.id`；查询层按租户权限路由与过滤。

**材料——核对手段**：用两个测试租户 A/B 与平台运营身份，分别发起查询，验证隔离与双视角清单。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 租户 A 身份查询 B 的遥测/会话 | 被拒绝（权限过滤，仅返回本租户数据） |
| 2 | 租户 A 自查 | 只见本租户健康/SLO/用量/会话 |
| 3 | 平台运营视角 | 全量健康 + TopN 大户（占用排行可下钻到会话） |
| 4 | 差体验定位 | 平台可查 SLO 达成率排行，定位差体验租户到具体会话 |
| 5 | 配额联动 | TopN 大户与配额治理（教程 03-React前端与AgenticUI/02-React与SSE流式UI）可联动 |

**失败排查**：①租户越权可见 → 查询层权限过滤缺失/`tenant.id` 未注入，回查 02 标签与查询路由；②平台看不到 TopN → 聚合未按租户维度汇总；③差体验定位断 → 会话关联键缺失，回 01/03。
