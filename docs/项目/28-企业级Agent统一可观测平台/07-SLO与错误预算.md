## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①双层 SLO（技术：可用/延迟；业务：成功率/满意度）②错误预算与变更冻结联动 ③燃烧率（快烧/慢烧）分级告警 |

**本迭代验收**：①双层 SLO 可见（达成率/预算余量）②预算耗尽自动冻结变更（联动发布）③燃烧率分级告警准确。

## 二、双层 SLO 与错误预算

```java
// 概念代码：Agent SLO 体系
enum AgentSlo {
    TECH_AVAIL(0.995),      // 技术可用性(非5xx)
    TECH_P95_MS(2500),      // 首 Token P95
    BIZ_SUCCESS(0.92),      // 业务成功率(会话完成且达标)
    BIZ_SATISFY(0.85);      // 满意度(正反馈占比)
}
// 错误预算 = (1-SLO)×窗口流量; 预算耗尽 → 冻结非紧急变更(联动23/26发布管道)
// 燃烧率 = 实际错误率/预算错误率: >14.4(1h)快烧P0 / >6(6h)慢烧P1
```

**要点**：**业务 SLO 比技术 SLO 更重要**——服务全绿但答非所问（业务 SLO 塌）仍是故障；业务 SLO 数据来自 05 的会话评分。
