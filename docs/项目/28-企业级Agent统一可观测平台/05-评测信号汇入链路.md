### 二.1 本节测试与验证（信号关联与飞轮联动）

**前置条件**：哨兵已按会话采样判分写入会话元数据；漂移告警可触发；26 采集管道可接收。

**材料——核对手段**：采样生成一个低分会话（score < 阈值），并在玻璃板按低分过滤；随后触发漂移告警观察时间线联动；最后一键推送飞轮。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 生成一个被哨兵判低分的会话 | 会话元数据带 score，玻璃板可按低分过滤出该会话 |
| 2 | 从低分会话下钻 | 能定位到该会话内哪一步导致低分（失败/耗时/上下文） |
| 3 | 触发漂移告警 | 告警与链路异动出现在同一条时间线上 |
| 4 | 对低分会话点"一键转飞轮" | 差例进入 26 采集管道（可对端核验收敛） |

**失败排查**：①过滤不出 → score 未写入会话元数据（哨兵采样未执行）；②下钻无定位 → 链路（01）+ 关联信号（03/04）未打通；③飞轮没收敛 → 26 采集接口/契约不匹配，核对推送契约。
