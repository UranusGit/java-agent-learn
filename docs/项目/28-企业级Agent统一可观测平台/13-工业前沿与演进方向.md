## 三、演进方向（按价值排序）

1. **LLM 根因增强**：06 的规则根因上叠加 LLM 归纳（把聚合证据总结成人话根因报告）——确定性定位 + LLM 表达。
2. **观测即评估**：05 的会话评分信号再进一步——线上实时的"观测版评测"（与 19 离线评测形成双闭环）。
3. **跨旗舰观测联动**：28 的信号驱动 26（飞轮修复）/24（预算暂停）/23（路由降级）——可观测中枢成为全旗舰的"神经中枢"。
4. **观测成本自治理**：遥测本身的成本（存储/采样）也纳入 04 成本视图——"观测自己的观测"。
5. **eBPF 层增强**：Sidecarless 场景的 LLM 流量观测下沉（呼应 [16-eBPF](../../项目/16-企业级Agent服务网格/09-Sidecarless与性能极限.md)）。

## 四、工程纪律复盘

- **不要**应用直连后端（统一管道）。
- **不要**让 Prompt 明文落遥测（processor 脱敏）。
- **不要**只看技术 SLO（业务 SLO 才是 Agent 的真健康）。
- **务必**信号挂链路（孤立报表=人肉拼接）。
- **务必**自动回滚带防护门（误回滚比故障更糟）。
