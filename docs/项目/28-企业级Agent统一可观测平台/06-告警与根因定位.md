## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①告警聚合（同源抑制/时间窗合并）②依赖拓扑上的根因定位（首发故障 vs 连锁反应）③根因建议（规则库+历史相似案例） |
| **影响了哪些模块** | 新增 AlertHub + RcaEngine |

**本迭代验收**：①风暴聚合为 ≤3 条根因告警 ②根因含依赖定位（哪个服务首发）③建议率 ≥80%（00 验收④）。

## 二、根因树（依赖拓扑定位）

```java
// 概念代码：拓扑根因
public RcaResult analyze(List<Alert> storm) {
    var graph = topo.of(storm);                  // 按调用依赖建图(网关→模型→工具→检索)
    var origin = graph.findOrigins(storm);       // 入度为0的故障节点=首发(非被连带)
    return RcaResult.of(origin,
        suggestion(origin),                       // 规则建议(如"模型网关5xx→查上游限流")
        evidence(storm));                         // 聚合证据(受影响链路样本)
}
```
