## ADR-01：统一 OTel 管道

**决策**：所有遥测经 Collector 管道，应用不直连后端。

**背景**：直连导致多后端改造/重复发送/无统一脱敏。

**取舍**：多一跳运维，换取治理统一（脱敏/采样/标签单点）。

## ADR-02：脱敏/采样在 processor

**决策**：敏感内容清洗与采样策略集中在管道 processor。

**背景**：应用侧各处脱敏易漏；采样应用侧做无法统一。

**取舍**：管道 CPU 开销，换安全一致。

## ADR-03：信号挂链路

**决策**：成本/评测信号通过 traceId/sessionId 与链路关联，同时间线呈现。

**背景**：孤立报表仍需人肉对时间。

**取舍**：信号写入多一次关联，换"一块屏定位"。

## ADR-04：三视图按角色

**决策**：SRE/业务/财务三视图，同数据不同切片。

**背景**：单一视图要么过技术要么过泛。

**取舍**：视图层开发量，换各角色可用性。

## ADR-05：usage 不采样

**决策**：Token/成本走预聚合指标，不受 trace 采样影响。

**背景**：成本计量必须全量（对账/预算）。

**取舍**：指标存储全量，换成本准确（呼应 20 对账纪律）。

## ADR-06：根因规则先行

**决策**：根因=依赖拓扑确定性定位 + 规则/历史建议；LLM 仅辅助。

**背景**：告警风暴下确定性聚合比 LLM 分析可靠且快。

**取舍**：建议覆盖率有限（≥80%），换定位确定性（呼应 09-AIOps 同结论）。

## ADR-07：双层 SLO 业务优先

**决策**：技术 SLO（可用/延迟）+ 业务 SLO（成功/满意）；业务塌=故障。

**背景**：服务全绿但答非所问仍是事故。

**取舍**：业务 SLO 依赖评分数据（05 前置）。

## ADR-08：自动回滚双防护门

**决策**：仅变更窗口内自动回滚 + 高风险人工确认。

**背景**：无限制自动回滚会误动作引发更大故障。

**取舍**：自动范围收窄，换安全闭环。

## 决策代价回顾

- ADR-01 管道 = 运维组件（HA 部署）。
- ADR-03 关联 = 写入放大（按价值选信号关联）。
- ADR-07 业务 SLO = 依赖评分（哨兵前置建设）。
