## 二、关键详解

### ADR 16-00：Mesh 而非平台收口

- **上下文**：存量异构 Agent 群（Python/JS/老 Java，多团队）需统一治理。
- **备选**：①中心平台网关（14 式）②SDK 化改造③Mesh 旁路。
- **决策**：③——零改造+本地执行+地理不绕行。
- **取舍**：②治理表达力最强但改造成本/组织阻力大；③引入 Sidecar 运维复杂度与 5ms 延迟。绿地统一栈仍应选平台（00 §八对照表）。
- **可回滚**：逃生门+按 ns 摘标签逐步退网。

### ADR 16-05：凭证只在 Sidecar

- **上下文**：Agent 绕过治理的逃逸必须封死。
- **备选**：①审计威慑②网络 ACL 白名单 Sidecar③上游凭证（Key）只在 Sidecar、身份绑定。
- **决策**：③——绕过=无 Key 无身份=物理连不通（比检测型防御强一档）。
- **可回滚**：凭证回迁 Agent（治理降级）。

### ADR 16-09：双进程热切升级

- **上下文**：数据面自身升级不能等于全网重启（长 SSE 断流）。
- **备选**：①滚动重启②双进程热切+治理状态交接。
- **决策**：②——在途流服务完、熔断窗口/限流桶序列化交接、金丝雀+自动回滚。
- **取舍**：双进程瞬时内存翻倍（Pod 预算上调）；换来零中断。
