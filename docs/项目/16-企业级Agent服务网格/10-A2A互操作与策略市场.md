# 10-A2A 互操作与策略市场——跨组织协作 / 策略资产共享

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ① SVID↔Agent Card 映射（网格身份对外可发现/可验证）② 跨组织委托（A2A 任务：外组织 Agent 经网格受控调用本组织能力）③ 策略市场（特征库/规则包/模板的发布-订阅-版本化）④ 委托不放大（跨组织权限 ⊆ 原始授权+显式 scope） |

| **上一版痛点** | 网格内闭环、对外无标准互操作；治理经验无法规模化复制（09 §六） |

### 二.1 本节测试与验证（Card 发布/发现/验证）

**前置条件**：SVID↔Agent Card 身份映射服务 + Card 目录（`/.well-known`）+ SVID 验签实现。

**材料 A——Card 闭环剧本**：外组织 Agent 发现 → 验签 → 发出 A2A 任务。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 本网格发布 Card（SVID 签名） | 外组织目录可发现该 Card |
| 2 | 材料 A：外组织 Agent 发现 + 验签 | SVID 验签通过 |
| 3 | 外组织经网格受控调用本组织能力 | 全程双向审计可查（本组织 + 回调外组织） |

**失败排查**：①验签失败→信任锚未互认（联邦前置条件缺失）；②全程无审计→委托调用未接 §四 审计流。

## 三、委托不放大（跨组织铁律）

```java
// 委托 token：外组织签发 → 本组织网格验证
// 规则：scope 显式列出可调能力（单能力单次/短 TTL 5min）
//      网关侧再取交集：委托 scope ∩ 本组织对外授权 → 执行
//      尝试越权（token 外能力）→ EPERM+双向审计（本组织+回调外组织告警）
```

### 三.1 本节测试与验证（委托不放大）

**前置条件**：委托 token 签发 + scope 交集校验（委托 scope ∩ 本组织对外授权）+ EPERM + 双向审计实现。

**材料 B——越权调用**：委托 token 请求 scope 外能力。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | scope 内能力调用 | 通（委托 scope ∩ 本组织对外授权 → 执行） |
| 2 | 材料 B：请求 token 外能力 | EPERM 拒绝 + 双向审计（本组织 + 回调外组织告警） |
| 3 | 核对最小授权 | scope 显式列出可调能力（单能力单次 + 短 TTL 5min），不放大 |

**失败排查**：①越权被放行→未做 scope ∩ 授权交集（直接执行 token 原始 scope）；②越权无审计→回调外组织告警缺失。

## 五、全篇回归验证（手工测试与验证）
**前置条件**：Agent Card 发布/发现+SVID 跨验+委托 scope+策略市场订阅实现。

**材料 A——Card 闭环剧本**；**材料 B——越权调用**（scope 外能力）；**材料 C——市场策略** llm-security-baseline v2.4。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 材料A：发布→外组织发现→调用 | SVID 验签通过；全程双向审计可查 |
