## 三、A/B 实验纪律

| 要素 | 规范 |
|------|------|
| 分流 | 按会话哈希（同人同组）；样本量预计算（目标效应+α=0.05） |
| 指标 | 主指标（信任分/任务完成率）+ 护栏指标（安全维不许跌） |
| 判定 | 显著性 p<0.05 才结论；护栏破即止损 |
| 时长 | ≥2 个完整业务周期（防星期效应） |
| 留档 | 实验报告归档（决策可回溯） |

## 四、验证包（手工测试与验证）
**前置条件**：差例归因+工单+AB 分流/显著性+金标挖掘实现。

**材料 A——差例注入**：灌入一批 Prompt 缺陷导致的低分例。

**材料 B——AB 模拟**：两版本分流数据（预生成带差异的样本）。

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 材料A | 归因=Prompt 缺陷 → 工单 → 修复 → 回归通过 → 上线全链走通 |
| 2 | 材料B | 显著性判定生效（p<0.05 才结论）；护栏（安全维）破即止损 |
| 3 | 挖掘统计 | 差例月产 ≥30 金标候选；攻击成功例自动进对抗种子队列 |
| 4 | 飞轮周报 | 修复 N 项/信任分变化 Δ 可查（闭环追踪） |
| 5 | 归因四类各注入一批 | Prompt/知识/检索/规则四类归因各自正确（≥80%） |

**失败排查**：①归因错→差例缺检索命中数据（归因输入不全）；②假阳性→未做样本量预计算（小样本就判显著）；⑤知识类归因错→知识版本未附在差例上下文。
