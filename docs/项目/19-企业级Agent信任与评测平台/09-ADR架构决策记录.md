## 二、关键详解

### ADR 19-00：评测即基础设施

- **备选**：①各项目自建评测 ②集中评测平台。
- **决策**：②——金标与判分标准是护城河（AWS 共识），分散=每次重建且不可比。
- **取舍**：平台要服务多场景（场景权重模板化解决）。

### ADR 19-02：指纹防污染

- **备选**：①流程约定（别把金标混进微调）②指纹强制拒收。
- **决策**：②——约定必被违反；管道级拒收才可靠。
- **代价**：数据准备多一步指纹比对（值得）。

### ADR 19-08：双卡闸门

- **备选**：①仅总分 ②总分+分维下限。
- **决策**：②——0.9 平均可能藏着 0.6 的安全；风控场景安全下限上调至 0.99。
