## 二、信任模型（五维评分）

| 维度 | 度量 | 数据源 |
|------|------|--------|
| 质量 | 任务完成率/忠实度/相关度 | 金标+官方 Evaluator |
| 安全 | 注入拦截率/越权率/有害输出率 | 红队集+在线审核 |
| 稳定 | 延迟/错误率/降级率波动 | 在线监控 |
| 成本 | Token 效率/单位任务成本 | 计量 |
| 满意 | 用户反馈/投诉/采纳 | 反馈流 |

**信任分 = 五维加权（权重按场景配置：风控场景安全×3、客服场景满意×2）**——单一分数可比较，多维可解释。
