## 二、关键详解

### ADR 15-00：OS 隐喻作为组织骨架

- **上下文**：Agent 数量爆炸后，平台需要组织"多进程共享资源"的复杂度。
- **备选**：①业务化组织（按客服/风控等场景分包）②OS 隐喻组织。
- **决策**：②——OS 是该问题域唯一被 40 年验证的成熟答案；隐喻同时给出沟通语言（"挂起""信号""配额"团队秒懂）。
- **取舍**：隐喻有过度套用风险（如强行做"内核锁"）——纪律：**映射到机制才用，只借名词不用**。
- **可回滚**：模块边界真实，去隐喻重命名不影响结构。

### ADR 15-03：挂起=快照+线程退出

- **上下文**：HITL 审批可能 24h 后回来，长任务可休眠数天。
- **备选**：①线程睡眠等待 ②状态外化（快照）+线程退出。
- **决策**：②——睡眠占线程/内存/配额；外化后零占用，唤醒=新线程续跑。
- **取舍**：快照有序列化成本（ms 级）与版本兼容负担（进程定义演进需兼容旧快照）。
- **可回滚**：短期等待（<5min）可退化线程内 park（权衡点可配）。

### ADR 15-08：抢占只在排队边界

- **上下文**：RT 进程（风控）需 100ms 级响应，但模型调用发出即计费。
- **备选**：①取消在途 HTTP 调用 ②只抢占排队位。
- **决策**：②——撕已发出调用=白付钱+上游状态不确定；排队位插队零成本即达标。
- **可回滚**：极端场景（灾难响应）可开"硬取消"开关（自担成本）。

### ADR 15-10：SIG_APPROVE 挂起零占用

- **上下文**：高危工具需人工审批；等待期不能占资源。
- **决策**：WOULD_BLOCK 返回 + BLOCKED 状态 + SIG_APPROVE 唤醒（与 ADR 15-03 同构）。
- **取舍**：进程需理解 WOULD_BLOCK 重发语义（编排循环多一个分支）——由内核 SDK 封装对业务透明。

### ADR 15-12：fork-join 快速失败（failFast 组播取消）

- **上下文**：08 并行子任务，其中一个失败时其余子进程仍在空耗资源、执行已无意义的工具调用。
- **备选**：①全部子进程跑完再聚合（allOf）②failFast：首个失败即组播 SIG_CANCEL(pgid) 取消其余。
- **决策**：②——快速失败止损，避免其余子进程继续烧 Token 与做无用功。
- **取舍**：失败即取消可能中断尚有价值的子任务——由调用方用 `ForkSpec.failFast` 显式选择，默认关闭（全完成语义）。
- **可回滚**：`failFast=false` 即回退到全部完成后再聚合。

### ADR 15-13：守护进程退避拉起 + 熔断上限

- **上下文**：08 常驻 daemon 崩溃需自动拉起，但无上限的重启会陷入"拉起→再崩→再拉起"的崩溃风暴。
- **备选**：①立即无限重启 ②退避重试（1s/2s/5s），连续 5 次失败转 STOPPED + 告警。
- **决策**：②——退避给下游与内核恢复时间，熔断上限防无限重启风暴耗尽资源。
- **取舍**：熔断后 daemon 停摆需人工介入——以告警 + 双人评审恢复，避免静默失联。
- **可回滚**：调大退避上限或改 `restart=always` 可放宽拉起强度。

### ADR 15-14：进程沙箱声明式（seccomp 式，非 OS 级强制）

- **上下文**：09 失控进程即使全在能力表内也可高频调用/狂写记忆/长跑不退；OS 级 seccomp/LSM 对 Java 进程内太重、且跨部署形态难以统一。
- **备选**：①OS 级 seccomp/LSM 强制 ②声明式沙箱：SandboxSpec 随进程定义下发，内核在 syscall 出口强制频率/速率/白名单/时长墙。
- **决策**：②——Java 层可测可配，与能力表双层互补（能力表=能做什么，沙箱=做的量级与方式）。
- **取舍**：非 OS 级强制，逃逸面仍在（如 JVM 自身漏洞）——声明为"概念内核"，高合规场景需 OS 层补充。
- **可回滚**：沙箱规格即配置，调 `violation: log` 即降级为观测。

### ADR 15-15：租约停写（分区时少数派只读）

- **上下文**：10 脑裂分区时若多数/少数派同时写共享状态→双重调度/数据分叉。
- **备选**：①分区时继续写（简单但双写分叉）②写共享状态前必须持租约（TTL 10s），分区少数派租约过期自动停写降级只读，恢复后追平。
- **决策**：②——配额/调度的双重执行比短暂不可用更危险，宁可只读不可双写。
- **取舍**：少数派短暂不可用（只读）——以告警 + 快速追平收窄窗口。
- **可回滚**：调大租约 TTL 或允许单实例临时降级写（仅应急）。
