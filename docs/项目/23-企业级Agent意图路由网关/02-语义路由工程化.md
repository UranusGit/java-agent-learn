# 02-语义路由工程化（EmbeddingModel 向量化路由）

> **定位**：把 01 的"两个示例"扩展成**可路由多意图的语义路由**：示例句缓存、多方案对比（规则 vs 语义 vs LLM）、阈值初步标定。核心洞察：**语义路由的覆盖度取决于示例句，命门是阈值**。前置阅读：[01-最小Demo](01-最小Demo.md)、[附录 20/00-路由表与语义路由](../../附录/20-路由与推理策略/00-路由表与语义路由.md)。
>
> **铁律 0**：`EmbeddingModel#embed(String)/embed(List<String>)` javap 实证；示例句向量预计算缓存（不重复 embed）。

## 一、四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ①意图→示例句集合（每意图多句）②示例向量启动预计算缓存 ③按余弦最高分路由 ④三方案横向对比附表 |
| **影响了哪些模块** | MinimalRouter → 重构为 SemanticRouter（意图驱动） |
| **架构如何演进** | 从 2 意图 switch 演进为"意图枚举 + 示例句 Map + 预计算向量表" |
| **上一版痛点** | 意图越多 switch 越臃肿；每类只有 1 句示例覆盖不足；阈值写死 0.6 |

**本迭代验收**：10 个意图 × 平均 15 句示例；路由延迟 ≤ 40ms（示例已缓存）；预留阈值可配置。

## 二、示例句管理 + 向量缓存

```java
// 概念代码：语义路由工程化
@Component
public class SemanticRouter {
    private final EmbeddingModel embeddingModel;
    private final RouteConfig routeConfig;            // 阈值/意图配置（03 迭代开始数据化）

    // 意图 → 示例句（每意图 10~20 条，覆盖变体/口语/同义）
    // 启动预计算：每个示例句 embed 一次，线上只对用户输入 embed 一次
    private Map<RouteKey, List<float[]>> exampleVecCache = new ConcurrentHashMap<>();

    @PostConstruct
    void preCompute() {
        for (var e : routeConfig.intentExamples().entrySet()) {
            List<float[]> vecs = embeddingModel.embed(e.getValue());  // embed(List<String>) 实证
            exampleVecCache.put(e.getKey(), vecs);
        }
    }

    RouteKey route(String input) {
        float[] v = embeddingModel.embed(input);
        RouteKey best = UNKNOWN; double bestScore = -1;
        for (var e : exampleVecCache.entrySet()) {
            double score = e.getValue().stream()
                    .mapToDouble(ex -> cosine(v, ex)).max().orElse(0);
            if (score > bestScore) { bestScore = score; best = e.getKey(); }
        }
        double threshold = routeConfig.intentThreshold(best);  // 按意图独立阈值
        return bestScore >= threshold ? best : UNKNOWN;
    }
}
```

## 三、三方案选型矩阵（写进架构决策）

| 维度 | 规则路由 | 语义路由 | LLM 分类 |
|------|---------|---------|---------|
| 延迟 | ~0ms | ~30ms | ~200ms+（多一轮推理） |
| Token 成本 | 0 | ~1 次 embedding | 每次推理 |
| 语义泛化 | ❌ 只认字面 | ✅ 认意思 | ✅ 最灵活 |
| 可解释性 | 最强（规则可读） | 中（看相似度） | 弱（黑盒） |
| 新意图适配 | 加规则快 | 补示例句快 | 改分类词表 |
| 适用 | 高频确定性词 | 类别有限有示例 | 开放意图 |

**结论**：三层漏斗（规则 → 语义 → LLM）是标准解，**确定性先行、LLM 收尾**——这套取舍会记入 12-ADR。
