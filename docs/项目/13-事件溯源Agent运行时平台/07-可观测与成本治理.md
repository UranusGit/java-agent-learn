### 3.3 归因投影：`TokenUsageProjector.java`（成本 = 日志投影）

```java
package com.group.session.meter;

import com.group.session.event.AssistantMessage;
import com.group.session.event.SessionEvent;
import org.springframework.stereotype.Component;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * 成本归因 = 会话日志的投影（单写多读：不单独建成本表）。
 * 折叠所有 assistant/message 事件，按 businessLine 聚合 token。
 */
@Component
public class TokenUsageProjector {

    /** 事件 data 里需要携带 usage 与 businessLine（v1 的 AssistantMessage 扩展字段）。 */
    public Map<String, Long> aggregateByBusinessLine(List<SessionEvent> events) {
        Map<String, Long> result = new HashMap<>();
        for (SessionEvent e : events) {
            if (e instanceof AssistantMessage am) {
                long tokens = estimateTokens(am.content());   // 无 usage 时启发式
                String line = am.businessLine() == null ? "unknown" : am.businessLine();
                result.merge(line, tokens, Long::sum);
            }
        }
        return result;
    }

    /** 启发式回退：字符数/4（对应 dsh token-meter 的 CHARS_PER_TOKEN）。 */
    private long estimateTokens(String content) {
        if (content == null) return 0;
        return Math.max(1, content.length() / 4);
    }
}
```

> ⚠️ 需要给 v1 的 `AssistantMessage` record 加一个字段 `businessLine`（v6 的模型调用已带业务线）。改 record 时**更新 v1 的事件定义**，保持 `data JSONB` 兼容（新增字段，旧数据读默认 null）。

### 3.4 预算治理：`BudgetPolicy.java` + `BudgetService.java`

```java
package com.group.control.budget;

/** 预算策略（Control Plane 下发，v7 支持按租户覆盖）。 */
public record BudgetPolicy(String businessLine, long monthlyTokens,
                           double warnRatio, double hardCapRatio,
                           String fallbackModel) {}
```

```java
package com.group.control.budget;

import com.group.session.meter.TokenUsageProjector;
import org.springframework.stereotype.Service;

import java.util.Map;

/** 预算执行：归因投影实时比对，超阈值告警/降级。 */
@Service
public class BudgetService {

    private final TokenUsageProjector projector;

    public BudgetService(TokenUsageProjector projector) {
        this.projector = projector;
    }

    public String check(Map<String, Long> usageByLine, BudgetPolicy policy) {
        long used = usageByLine.getOrDefault(policy.businessLine(), 0L);
        double ratio = (double) used / policy.monthlyTokens();
        if (ratio >= policy.hardCapRatio()) {
            return "HARD_CAP:" + policy.fallbackModel();   // 超 100% → 降级模型
        }
        if (ratio >= policy.warnRatio()) {
            return "WARN";                                  // 超 80% → 告警
        }
        return "OK";
    }
}
```

### 3.5 计量零业务侵入：`LlmObservationConfig.java`（用 Observation，不动业务代码）

```java
package com.group.gateway.meter;

import org.springframework.ai.chat.observation.ChatModelObservationConvention;
import org.springframework.ai.chat.observation.DefaultChatModelObservationConvention;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

/**
 * 观测零侵入：Spring AI 自动装配 gen_ai.* 语义计量（ChatModelMeterObservationHandler + 默认约定），
 * 业务代码不感知计量（[教程 22-全链路可观测性]）。
 */
@Configuration
public class LlmObservationConfig {

    /** 如需自定义观测名/标签，继承 DefaultChatModelObservationConvention 覆盖 getName()/getLowCardinalityKeyValues(...)。 */
    @Bean
    public ChatModelObservationConvention chatModelObservationConvention() {
        return new DefaultChatModelObservationConvention();   // 使用框架默认 gen_ai 约定
    }
}
```

> ⚠️ `ChatModelObservationConvention` 的精确接口与默认约定类名，以你引入的 Spring AI 2.0 版本为准（[附录 05-SpringAI2-API基准/02-Tool与Observation真实API §3]）。**语义不变：计量走 Observation，业务零侵入。**

## 4. ADR 演进决策

### ADR 013-14：成本归因用日志投影，不单独建成本表
- **Why**：成本可重放、可审计、可重算（[附录 15/12 §M6]）——单写多读

### ADR 013-15：计量走 Observation 不改业务
- **Why**：观测是横切关注点，用框架级机制而非业务自埋（[教程 22-全链路可观测性]）

## 5. 验收与遗留痛点

**验收**：gen_ai.* 指标齐全、归因误差 ≤ 2%、P99/错误率接面板、预算告警+降级、零业务侵入。

**遗留痛点（供 v7 决策）**：业务线=隐含租户但无真隔离；Prompt/模型全局一份无灰度；单实例无高可用。
