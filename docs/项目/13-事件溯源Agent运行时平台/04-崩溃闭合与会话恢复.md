### 3.1 `SessionWriteBuffer.java`（批量写缓冲 + 显式 flush）

```java
package com.group.agent.event;

import org.springframework.stereotype.Component;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;

/**
 * 固定窗口批量写：append 入队，窗口到期批量落库；显式 flush() 立即落库。
 * 崩溃最多丢「未 flush 的窗口尾部」——通过只丢弃撕裂的最后记录保证一致性。
 */
@Component
public class SessionWriteBuffer {

    private static final long WINDOW_MS = 200;

    private final SessionEventStore store;
    private final Map<String, List<SessionEvent>> pending = new ConcurrentHashMap<>();
    private final ScheduledExecutorService scheduler = Executors.newSingleThreadScheduledExecutor();

    public SessionWriteBuffer(SessionEventStore store) {
        this.store = store;
        scheduler.scheduleWithFixedDelay(this::flushAll, WINDOW_MS, WINDOW_MS, TimeUnit.MILLISECONDS);
    }

    /** 入队（不立即落库）。 */
    public void enqueue(SessionEvent e) {
        pending.computeIfAbsent(e.sessionId(), k -> new ArrayList<>()).add(e);
    }

    /** 立即落库（turn 边界/审批点调用，保证关键事实 durable）。 */
    public synchronized void flush(String sessionId) {
        List<SessionEvent> batch = pending.remove(sessionId);
        if (batch != null && !batch.isEmpty()) {
            store.appendBatch(sessionId, batch);   // 单事务批量
        }
    }

    private synchronized void flushAll() {
        for (String sessionId : List.copyOf(pending.keySet())) {
            flush(sessionId);
        }
    }
}
```

### 3.2 `SessionEventStore` 追加批量方法（v3）

```java
    // 追加到 SessionEventStore：批量单事务写，保证 seq 连续
    @Transactional
    public void appendBatch(String sessionId, List<SessionEvent> events) {
        long expected = lastSeq(sessionId) + 1;
        for (SessionEvent e : events) {
            if (e.seq() != expected) {
                throw new IllegalStateException("seq 不连续: session=" + sessionId
                        + " expected=" + expected + " got=" + e.seq());
            }
            expected++;
        }
        // 批量 INSERT（单事务）——一次性插入整个批次
        for (SessionEvent e : events) {
            insertOne(e);
        }
    }

    private long lastSeq(String sessionId) {
        return jdbc.sql("SELECT seq FROM session_event WHERE session_id=:sid ORDER BY seq DESC LIMIT 1")
                .param("sid", sessionId).query(Long.class).optional().orElse(-1L);
    }

    private void insertOne(SessionEvent e) {
        try {
            jdbc.sql("INSERT INTO session_event(session_id, seq, type, time, data) VALUES(:sid,:seq,:type,:time,CAST(:data AS jsonb))")
                    .param("sid", e.sessionId()).param("seq", e.seq())
                    .param("type", e.getClass().getSimpleName()).param("time", e.time())
                    .param("data", mapper.writeValueAsString(e)).update();
        } catch (Exception ex) {
            throw new IllegalStateException("事件 JSON 序列化失败", ex);
        }
    }
```

### 3.3 `RecoveryService.java`（崩溃闭合孤儿 turn）

```java
package com.group.agent.event;

import org.springframework.stereotype.Service;

import java.util.ArrayList;
import java.util.List;

/**
 * 恢复逻辑：检测孤儿 turn，合成闭合事件（不截断已发生事实）。
 * 闭合而非截断——单 turn 可能巨大，截断会丢审计。
 */
@Service
public class RecoveryService {

    private final SessionEventStore store;

    public RecoveryService(SessionEventStore store) {
        this.store = store;
    }

    /** 恢复一个会话：加载 → 修复孤儿 → 返回一致的事件列表。 */
    public List<SessionEvent> recover(String sessionId) {
        List<SessionEvent> events = new ArrayList<>(store.load(sessionId));
        List<SessionEvent> closers = closeOrphanTurns(sessionId, events);
        if (!closers.isEmpty()) {
            store.appendBatch(sessionId, closers);      // 修复也要落库（持久闭合）
            events.addAll(store.load(sessionId));        // 重新加载含闭合事件
        }
        return events;
    }

    /** 扫描未闭合 turn / 孤儿工具调用，合成 interrupted 闭合事件。 */
    List<SessionEvent> closeOrphanTurns(String sessionId, List<SessionEvent> events) {
        int lastTurnStart = lastIndexByType(events, TurnStart.class);
        int lastTurnEnd   = lastIndexByType(events, TurnEnd.class);
        List<SessionEvent> closers = new ArrayList<>();
        long seq = events.isEmpty() ? 0 : events.get(events.size() - 1).seq();
        long t = System.currentTimeMillis();

        if (lastTurnStart > lastTurnEnd) {               // 有未闭合 turn
            int lastToolCall   = lastIndexByType(events, ToolCall.class);
            int lastToolResult = lastIndexByType(events, ToolResult.class);
            if (lastToolCall > lastToolResult) {         // 孤儿工具调用
                ToolCall orphan = (ToolCall) events.get(lastToolCall);
                closers.add(new ToolResult(sessionId, ++seq, t, orphan.callId(),
                        "{\"error\":\"INTERRUPTED\"}", List.of()));
            }
            closers.add(new TurnEnd(sessionId, ++seq, t, "interrupted"));
        }
        return closers;
    }

    private int lastIndexByType(List<SessionEvent> events, Class<?> type) {
        for (int i = events.size() - 1; i >= 0; i--) {
            if (type.isInstance(events.get(i))) return i;
        }
        return -1;
    }
}
```

### 3.4 冷读阶梯：`SessionProjectionCache.java` + `SessionProjector` 改造

**`SessionProjectionCache.java`（投影快照 + 增量回放）**：

```java
package com.group.agent.event;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;

import java.util.List;
import java.util.Optional;

/** 冷读阶梯：快照 + 增量回放，列表读永不加载全日志。 */
@Component
public class SessionProjectionCache {

    private final JdbcClient jdbc;
    private final SessionEventStore store;
    private final SessionProjector projector;

    public SessionProjectionCache(JdbcClient jdbc, SessionEventStore store,
                                  SessionProjector projector) {
        this.jdbc = jdbc;
        this.store = store;
        this.projector = projector;
    }

    public record Snapshot(long checkpointSeq, List<org.springframework.ai.chat.messages.Message> history) {}

    /** 读历史：有快照走「快照 + 增量回放」，否则全量。 */
    public Snapshot derive(String sessionId) {
        Optional<Long> checkpoint = jdbc.sql(
                "SELECT checkpoint_seq FROM session_projection WHERE session_id=:sid")
                .param("sid", sessionId).query(Long.class).optional();
        if (checkpoint.isEmpty()) {
            List<SessionEvent> all = store.load(sessionId);
            return new Snapshot(all.isEmpty() ? 0 : all.get(all.size() - 1).seq(),
                    projector.deriveMessages(all));
        }
        long from = checkpoint.get() + 1;
        List<SessionEvent> tail = store.loadFrom(sessionId, from);   // 增量
        return new Snapshot(from - 1 + tail.size(),
                projector.deriveMessages(store.load(sessionId)));    // 简版：全量重算，生产可增量 fold
    }

    /** turn/end 强制写快照（先 flush 保证日志已落盘——缓存永不超前日志）。 */
    public void checkpoint(String sessionId, SessionWriteBuffer buffer) {
        buffer.flush(sessionId);                      // 先 flush
        List<SessionEvent> all = store.load(sessionId);
        jdbc.sql("INSERT INTO session_projection(session_id, checkpoint_seq) VALUES(:sid,:seq) "
                + "ON CONFLICT (session_id) DO UPDATE SET checkpoint_seq=EXCLUDED.checkpoint_seq")
                .param("sid", sessionId)
                .param("seq", all.isEmpty() ? 0 : all.get(all.size() - 1).seq())
                .update();
    }
}
```

### 3.5 接线：`ChatService` 改用写缓冲 + 恢复

```java
package com.group.agent.service;

import com.group.agent.event.AssistantMessage;
import com.group.agent.event.SessionWriteBuffer;
import com.group.agent.event.RecoveryService;
import com.group.agent.event.SessionProjectionCache;
import com.group.agent.event.UserMessage;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.concurrent.atomic.AtomicLong;

/** ChatService 关键改造（v3）：append 全部改 buffer.enqueue；turn 边界 flush + checkpoint；会话首次访问先恢复。 */
@Service
public class ChatService {

    private final ChatClient chatClient;
    private final SessionWriteBuffer writeBuffer;
    private final SessionProjectionCache projectionCache;
    private final RecoveryService recoveryService;
    private final AtomicLong seq = new AtomicLong(0);   // 演示用；生产按会话独立计数器

    public ChatService(ChatClient chatClient, SessionWriteBuffer writeBuffer,
                       SessionProjectionCache projectionCache, RecoveryService recoveryService) {
        this.chatClient = chatClient;
        this.writeBuffer = writeBuffer;
        this.projectionCache = projectionCache;
        this.recoveryService = recoveryService;
    }

    public String chat(String sessionId, String message) {
        recoveryService.recover(sessionId);              // ③ 会话首次访问先恢复（崩溃闭合）
        long t = System.currentTimeMillis();
        writeBuffer.enqueue(new UserMessage(sessionId, seq.incrementAndGet(), t,
                message, UserMessage.Source.USER, List.of()));   // ① 写 user 事件（enqueue，不落库）
        String answer = chatClient.prompt()
                .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, sessionId))
                .call().content();
        writeBuffer.enqueue(new AssistantMessage(sessionId, seq.incrementAndGet(),
                System.currentTimeMillis(), answer, "deepseek", List.of()));   // ① assistant 事件
        writeBuffer.flush(sessionId);                    // ② turn 边界批量落库（单事务）
        projectionCache.checkpoint(sessionId, writeBuffer);   // ② 检查点（先 flush 后 checkpoint：缓存永不超前日志）
        return answer;
    }
}
```

**步骤与断言**：

| # | 操作 | 预期（PASS 判据） |
|---|------|------------------|
| 1 | 正常对话一轮（不崩溃） | 事件按序落库；写缓冲窗口（200ms）到期批量落库，`session_event` 行数正确（验收 3 写缓冲生效） |
| 2 | 材料 A：工具执行中 kill -9 | 崩溃点附近存在「`ToolCall` 已落、`ToolResult` 未落」的孤儿，或 `TurnStart` 后无 `TurnEnd` 的半截 turn |
| 3 | 重启后首次访问会话（触发 `recoveryService.recover`） | 恢复合成补 `ToolResult(INTERRUPTED)`（若孤儿）+ `TurnEnd(interrupted)` 落库（验收 1：无悬挂 turn） |
| 4 | 材料 B 恢复后重问 | 能续答且无中断残留；因异常被闭合闭合，会话不卡死 |
| 5 | 已提交事实保留核对 | 崩溃前已 flush 的事件 100% 保留在 `session_event`；`session_projection` 检查点在 turn 边界被写入（验收 2/5） |

**失败排查**：①恢复后仍有悬挂 turn→`closeOrphanTurns` 最后一个 `TurnStart > TurnEnd` 判断没触发（序列里 TurnStart/TurnEnd 顺序异常），或 `RecoveryService` 没在会话首次访问被调用；②崩溃丢已提交事件→`flush` 未在 turn 边界调用，写缓冲窗口尾部撕裂没处理；③冷读不走快照→`session_projection` 表未建或 `checkpoint()` 未在 turn/end 调 `buffer.flush` 先落库（缓存超前日志的纪律被违反）。

## 4. ADR 演进决策

### ADR 013-08：孤儿 turn 用「合成闭合」而非「截断」
- **Why**：闭合不丢事实，审计完整（[附录 14-开源代码深度分析/00-deepseek-harness/12-Java工程师借鉴手册 §M2]）
- **备选方案**：截断（丢审计）/ 保留悬挂（重建异常）/ 合成闭合（本文选择）

### ADR 013-09：写缓冲 + 显式 flush 点
- **Why**：「常规批量 + 关键点同步」是吞吐与可靠性的折中；关键事实（turn 边界、审批）不赌窗口
- **参考**：[附录 14-开源代码深度分析/00-deepseek-harness/12-Java工程师借鉴手册 §M3 §M8]

### 4.1 本节核对（ADR 013-08 / 013-09）
