## 1. 四问

| 问 | 答 |
|----|----|
| **新增了什么需求** | ① 危险工具默认拒绝，模型要调必须人工审批 ② 审批过程可审计 ③ API Key 不落明文，可热轮换 |
| **影响了哪些模块** | 工具执行（守卫位）、凭证层（新增 CredentialProvider）、事件日志（审批审计对） |
| **架构如何演进** | 工具从「默认放行」→「**fail-closed + 审批门**」；密钥从「配置明文」→「**引用 + 每操作解析**」 |
| **上一版痛点是什么** | ① 工具全放行 ② 无审批记录 ③ API Key 明文、轮换要重启 |

## 2. 目标与量化验收

| # | 目标 | 验收 |
|---|------|------|
| 1 | fail-closed | 危险工具（`delete_order`）无审批 = 拒绝执行 |
| 2 | 审批可审计 | `approval/asked` + `approval/decided` 成对落日志 |
| 3 | 一次性放行 | 审批是 `allowed-once`，下次再问 |
| 4 | 凭证热轮换 | 改 API Key 下一请求生效，无需重启 |
| 5 | 不落明文 | 配置/日志/错误无密钥明文 |

### 3.1 `ApprovalOutcome.java`（审批决策：sealed 穷尽）

```java
package com.group.agent.approval;

/** 审批结果（Java 21 sealed）：fail-closed 默认 Unavailable。 */
public sealed interface ApprovalOutcome permits
        AllowedOnce, Rejected, Cancelled, Unavailable {
    record AllowedOnce() implements ApprovalOutcome {}
    record Rejected(String reason) implements ApprovalOutcome {}
    record Cancelled() implements ApprovalOutcome {}
    record Unavailable() implements ApprovalOutcome {}
}
```

### 3.2 `ApprovalService.java`（审批审计对 + 挂起存储）

```java
package com.group.agent.approval;

import com.group.agent.event.SessionEventStore;
import org.springframework.stereotype.Service;

import java.time.Duration;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CompletableFuture;

/**
 * HITL 审批：approval/asked + approval/decided 成对落日志（审计可回放）。
 * 无 answerer / 超时 → Unavailable（fail-closed）。
 */
@Service
public class ApprovalService {

    private final SessionEventStore eventStore;
    private final Map<String, CompletableFuture<ApprovalOutcome>> pending = new ConcurrentHashMap<>();

    public ApprovalService(SessionEventStore eventStore) {
        this.eventStore = eventStore;
    }

    public static final class ApprovalAskedEvent {
        // 简化：直接复用一个 log-only 事件类型。生产用独立 record。
    }

    /** 发起审批：写 asked，挂起等待 answerer 决策。 */
    public ApprovalOutcome request(String sessionId, String toolName, String callId,
                                   String reason, Duration timeout) {
        String approvalId = UUID.randomUUID().toString();
        // 审计对前半：asked
        logAudit(sessionId, "approval/asked",
                "{\"approvalId\":\"" + approvalId + "\",\"toolName\":\"" + toolName
                + "\",\"callId\":\"" + callId + "\",\"reason\":\"" + reason + "\"}");

        CompletableFuture<ApprovalOutcome> future = new CompletableFuture<>();
        pending.put(approvalId, future);
        // fail-closed：超时 → Unavailable
        CompletableFuture.delayedExecutor(timeout.toMillis(), java.util.concurrent.TimeUnit.MILLISECONDS)
                .execute(() -> future.complete(new ApprovalOutcome.Unavailable()));

        ApprovalOutcome outcome = future.join();
        // 审计对后半：decided（含 outcome，成对闭合）
        logAudit(sessionId, "approval/decided",
                "{\"approvalId\":\"" + approvalId + "\",\"outcome\":\"" + outcome + "\"}");
        return outcome;
    }

    /** answerer 决策入口（审批 UI 调用）。 */
    public void decide(String approvalId, ApprovalOutcome outcome) {
        CompletableFuture<ApprovalOutcome> f = pending.remove(approvalId);
        if (f != null && !f.isDone()) f.complete(outcome);
    }

    private void logAudit(String sessionId, String type, String dataJson) {
        // 简化：写入会话事件表（真实实现新增 APPROVAL_ASKED / APPROVAL_DECIDED record）
        eventStore.appendRaw(sessionId, type, System.currentTimeMillis(), dataJson);
    }
}
```

### 3.3 审批守卫：`HumanApprovalToolManager.java`（ToolCallingManager 装饰器）

```java
package com.group.agent.tool;

import com.group.agent.approval.ApprovalOutcome;
import com.group.agent.approval.ApprovalService;
import com.group.agent.event.SessionEventStore;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.chat.model.Generation;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.ai.model.tool.ToolCall;
import org.springframework.ai.model.tool.ToolCallingChatOptions;
import org.springframework.ai.model.tool.ToolExecutionResult;
import org.springframework.ai.tool.ToolCallingManager;
import org.springframework.stereotype.Component;

import java.time.Duration;
import java.util.List;
import java.util.Set;

/**
 * 审批守卫（v2 的 ToolCallingManager 装饰器升级）：
 * 命中危险工具清单 → 必须人工审批，allowed-once 才放行；否则拒绝（fail-closed）。
 */
@Component
public class HumanApprovalToolManager implements ToolCallingManager {

    private final ToolCallingManager delegate;
    private final ApprovalService approvalService;
    private final SessionEventStore eventStore;
    private final Set<String> dangerousTools = Set.of("delete_order", "transfer_money");

    public HumanApprovalToolManager(ToolCallingManager delegate,
                                    ApprovalService approvalService,
                                    SessionEventStore eventStore) {
        this.delegate = delegate;
        this.approvalService = approvalService;
        this.eventStore = eventStore;
    }

    @Override
    public ToolExecutionResult executeToolCalls(Prompt prompt, ChatResponse chatResponse) {

        List<ToolCall> calls = extractToolCalls(chatResponse);
        String sessionId = sessionIdOf(prompt);

        for (ToolCall call : calls) {
            if (dangerousTools.contains(call.name())) {
                // 守卫：必须审批，allowed-once 才放行
                ApprovalOutcome outcome = approvalService.request(
                        sessionId, call.name(), call.id(), "危险工具", Duration.ofSeconds(30));
                if (!(outcome instanceof ApprovalOutcome.AllowedOnce)) {
                    // 拒绝：不执行，返回人工否决结果
                    return ToolExecutionResult.builder().addResponse(...)
                        // 实际构造一个"工具被拒绝"的结果——生产用 ToolExecutionResult 的拒绝分支
                        .build();
                }
                // allowed-once：只放行本次，下次再问
            }
        }
        return delegate.executeToolCalls(prompt, chatResponse);
    }

    private List<ToolCall> extractToolCalls(ChatResponse chatResponse) {
        return chatResponse.getResults().stream()
                .map(g -> g.getOutput().getToolCalls())
                .flatMap(List::stream).toList();
    }

    private String sessionIdOf(Prompt prompt) {
        return (String) ((ToolCallingChatOptions) prompt.getOptions()).getContext().get("sessionId");
    }
}
```

> ⚠️ 上面 `ToolExecutionResult.builder().addResponse(...)` 处的「拒绝构造」是示意，真实构造方式以你引入的 Spring AI 2.0 版本 API 为准（工具结果拒绝可用 `ToolExecutionResult.builder()` 或直接抛受控异常返回错误给模型）。**关键语义不变：危险工具无 `AllowedOnce` 审批 → 不执行**。

### 3.4 凭证缝：`CredentialProvider.java` + `ResolvedCredential.java` + `CredentialsLocalProvider.java`

```java
package com.group.agent.credential;

/** 凭证缝：配置只存引用，provider 持值，每操作解析。 */
public interface CredentialProvider {
    ResolvedCredential resolve(String ref);     // ref 如 "llm.deepseek.apiKey"
    CredentialInfo describe(String ref);        // 绝不返回值
    void set(String ref, String value);
    void unset(String ref);

    record ResolvedCredential(String value, String source) {}
    record CredentialInfo(boolean configured, String source, boolean writable) {}
}
```

```java
package com.group.agent.credential;

import org.springframework.stereotype.Component;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/** 本地凭证提供者：环境变量优先，其次本地库。空值处处视为不存在。 */
@Component
public class CredentialsLocalProvider implements CredentialProvider {

    private final Map<String, String> store = new ConcurrentHashMap<>();

    @Override
    public ResolvedCredential resolve(String ref) {
        String fromEnv = System.getenv(envName(ref));
        if (isPresent(fromEnv)) return new ResolvedCredential(fromEnv, "env");
        String fromStore = store.get(ref);
        if (isPresent(fromStore)) return new ResolvedCredential(fromStore, "local");
        return null;   // 未配置——空值=未配置，绝不当作已配置
    }

    @Override
    public CredentialInfo describe(String ref) {
        String value = resolve(ref);
        if (value == null) return new CredentialInfo(false, null, true);
        return new CredentialInfo(true, value.source(), false);
    }

    @Override
    public void set(String ref, String value) {
        if (value == null || value.isBlank()) {
            throw new IllegalArgumentException("凭证不可为空串——空值=未配置，请用 unset");
        }
        store.put(ref, value);
    }

    @Override
    public void unset(String ref) {
        store.remove(ref);
    }

    private String envName(String ref) {
        return ref.replace(".", "_").toUpperCase();   // llm.deepseek.apiKey -> LLM_DEEPSEEK_APIKEY
    }

    private boolean isPresent(String s) {
        return s != null && !s.isBlank();
    }
}
```

## 4. ADR 演进决策

### ADR 013-10：审批默认拒绝，批准只允许一次
- **Why**：fail-closed 是地板；`allowed-once` 兼顾可用性与不建立持久授权（[附录 15/12 §S5]）

### ADR 013-11：凭证用引用 + 每操作解析
- **Why**：轮换零重启；配置/日志/错误不含明文；空值=未配置（[附录 15/12 §S3 §S4]）

## 5. 验收与遗留痛点

**验收**：无审批危险工具被拒、审计对成对落日志、allowed-once、热轮换、无明文。

**遗留痛点（供 v5/v6 决策）**：
1. 单体膨胀（v5 微服务拆分）
2. 审批 UI 与引擎耦合（v5 审批服务独立）
3. 无 Token 计量归因（v6）
