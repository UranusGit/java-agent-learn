## 二、关键详解

### ADR 17-00：延迟预算倒推

- **上下文**：文本 Agent 的"功能优先"设计在实时域全错位。
- **备选**：①功能堆叠后优化 ②预算定架构。
- **决策**：②——先定 1.2s 往返/200ms 打断，再反推每环节预算与降级。
- **取舍**：②牺牲部分功能（重工具走异步补答而非同步等）。
- **可回滚**：非实时场景可整体退化为文本 Agent（降级矩阵极端行）。

### ADR 17-02：打断是一等公民

- **备选**：①播完再听（半双工）②真打断。
- **决策**：②——真人对话可随时插话；实现=VAD 能量门+全链取消（TTS 队列+在途生成）。
- **取舍**：状态机复杂度大增（会话需处理"被打断"语义与残留清理）。

### ADR 17-07：句级弃置

- **备选**：①违规整轮重来 ②只弃违规句。
- **决策**：②——播前逐句审，违规句丢弃重生成该句。
- **取舍**：上下文连贯需处理（重生成句带前文）；换来体验（其余内容不白说）。
