## 三、全链降级矩阵（SRE 联动）

| 环节故障 | 降级路径 | 用户感受 |
|---------|---------|---------|
| 流式 ASR | 保守 VAD+整句 ASR / 按键+文字 | 略慢仍可说 |
| 编排(LLM) | 本地话术库 FAQ 兜底 | 常见问题照答 |
| 流式 TTS | 预合成提示音+文字通道 | 变"看"模式 |
| 检索(05) | 空上下文+声明"信息可能不全" | 诚实降级 |
| 打断检测 | 全双工→按键轮替 | 退半双工 |
| 区域整体 | DNS 切邻区（会话重建 ≤500ms 恢复） | 短暂重连 |

```bash
# 演练：每月按矩阵逐项"拔插头"（复用平台混沌纪律）——降级路径不演练=不存在
```
