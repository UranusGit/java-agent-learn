|---|------|------|

## 3. 引擎选型与显存

> **选型矩阵**（[调研 工业质检 2026 §边缘部署]）：

| 引擎 | 格式 | 适用 | 备注 |
|------|------|------|------|
| **Ollama** | GGUF Q4_K_M | 边缘/单用户/断网/原型 | 8B Q4 约 9.2GB 可跑工控机；~320 tok/s |
| **vLLM** | FP16/FP8/AWQ | 云端/高并发/多租户 | ~1450 tok/s；**不支持 GGUF**，AWQ 是质量最优 INT4 |
| llama.cpp | GGUF | CPU-only 极端边缘 | 低并发兜底 |

**显存公式**：`显存(GB) ≈ (参数量 × 量化位宽) / 8 × 1.25（KV Cache 开销）`——KV cache 与权重量化独立，AWQ 后"4GB"仍可能需要 10-30GB KV cache。

```java
package com.plant.iq.edge;

import io.micrometer.observation.ObservationRegistry;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.openai.OpenAiChatModel;
import org.springframework.ai.openai.OpenAiChatOptions;
import org.springframework.ai.openai.setup.OpenAiSetup;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.util.List;

/**
 * 双引擎网关：默认 ChatClient（spring.ai.openai → 云端 vLLM）做疑难会诊；
 * 本类只注册"边缘 Ollama"专属通道——不暴露 ChatModel Bean，避免与默认模型冲突。
 */
@Configuration
public class ModelGatewayConfig {

    @Value("${llm.edge.base-url}") private String edgeBaseUrl;
    @Value("${llm.edge.api-key}")  private String edgeApiKey;
    @Value("${llm.edge.model}")    private String edgeModelName;

    @Bean("edgeChatClient")
    public ChatClient edgeChatClient() {
        // Spring AI 2.0.0（javap 实证）：OpenAiChatModel.Builder 只收 openAiClient(OpenAIClient)/options(OpenAiChatOptions)，
        // 旧式 openAiApi(...)/defaultOptions(...) 已移除；OpenAIClient 由官方 helper OpenAiSetup.setupSyncClient 构建
        // （与 starter 自动装配同一入口，见 OpenAiChatAutoConfiguration）。
        OpenAiChatModel edgeModel = OpenAiChatModel.builder()
                .openAiClient(OpenAiSetup.setupSyncClient(
                        edgeBaseUrl, edgeApiKey,            // baseUrl + apiKey
                        null, null, null, null,             // credential / azure 系列
                        false, false, edgeModelName,        // foundry / githubModels / model
                        null, 2, null, null,                // timeout / maxRetries / proxy / customHeaders
                        ObservationRegistry.NOOP, null, List.of()))  // observation / meter / customizers（List.of() 避免空迭代 NPE）
                .options(OpenAiChatOptions.builder()
                        .model(edgeModelName)
                        .build())
                .build();
        return ChatClient.builder(edgeModel)
                .defaultSystem("你是边缘质检助手——轻量模型，处理常规判级。")
                .build();
    }
}
```

### 4.4 `CloudReachability.java`（断网探测）

```java
package com.plant.iq.edge;

import org.springframework.stereotype.Component;
import org.springframework.web.reactive.function.client.WebClient;

import java.time.Duration;

@Component
public class CloudReachability {

    private final WebClient webClient;

    public CloudReachability(WebClient.Builder webClientBuilder) {
        this.webClient = webClientBuilder.build();
    }

    /** 探测云端健康端点；超时视为断网。调用方均为非 EventLoop 线程（工具/调度），block 可接受 */
    public boolean isReachable() {
        return Boolean.TRUE.equals(webClient.get()
                .uri("http://cloud-gateway/actuator/health")
                .retrieve()
                .bodyToMono(String.class)
                .timeout(Duration.ofSeconds(3))
                .map(s -> true)
                .onErrorReturn(false)
                .block());
    }
}
```

### 4.5 `ModelTierRouter.java`（路由/降级）

```java
package com.plant.iq.edge;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.stereotype.Service;

@Service
public class ModelTierRouter {

    private final ChatClient cloudChatClient;   // 默认通道 = 云端 vLLM（AgentConfig 中 @Primary）
    private final ChatClient edgeChatClient;    // 边缘 Ollama

    private final CloudReachability reachability;

    public ModelTierRouter(ChatClient cloudChatClient,
                           @Qualifier("edgeChatClient") ChatClient edgeChatClient,
                           CloudReachability reachability) {
        this.cloudChatClient = cloudChatClient;
        this.edgeChatClient = edgeChatClient;
        this.reachability = reachability;
    }

    public ChatClient route(String taskType) {
        if (!reachability.isReachable()) {
            return edgeChatClient;               // 断网: 一律边缘自治（不调云）
        }
        return switch (taskType) {
            case "routine_judge" -> edgeChatClient;   // 常规判级: 边缘（省延迟/成本）
            case "hard_consult" -> cloudChatClient;   // 疑难会诊: 云端
            default -> edgeChatClient;                 // 降级: 边缘兜底
        };
    }
}
```

### 4.6 断网边缘自治：`LocalBuffer` + `LocalAlarm` + `UpstreamPublisher` + `EdgeAutonomy`

```java
package com.plant.iq.edge;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.plant.iq.detect.StatSignal;
import org.springframework.stereotype.Component;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.util.List;

/** 断网本地缓冲（JSONL 落盘，恢复后增量同步——零丢失） */
@Component
public class LocalBuffer {

    private final ObjectMapper mapper;
    private final Path file;

    public LocalBuffer(ObjectMapper mapper) {
        this.mapper = mapper;
        this.file = Path.of(System.getProperty("java.io.tmpdir"), "edge-buffer.jsonl");
    }

    public void stash(StatSignal signal) {
        try {
            Files.writeString(file, mapper.writeValueAsString(signal) + "\n",
                    StandardOpenOption.CREATE, StandardOpenOption.APPEND);
        } catch (IOException e) {
            throw new IllegalStateException("边缘缓冲写入失败", e);
        }
    }

    public List<StatSignal> drain() {
        try {
            if (!Files.exists(file)) return List.of();
            List<StatSignal> all = Files.readAllLines(file).stream()
                    .map(this::readSignal)
                    .toList();
            Files.deleteIfExists(file);
            return all;
        } catch (IOException e) {
            throw new IllegalStateException("边缘缓冲读取失败", e);
        }
    }

    public boolean isEmpty() {
        return !Files.exists(file) || file.toFile().length() == 0;
    }

    private StatSignal readSignal(String line) {
        try {
            return mapper.readValue(line, StatSignal.class);
        } catch (IOException e) {
            throw new IllegalStateException("边缘缓冲解析失败: " + line, e);
        }
    }
}
```

```java
    public void publish(StatSignal signal) {

                .subscribe();   // 异步投递，不阻塞边缘线程
```

```java
package com.plant.iq.edge;

import com.plant.iq.detect.EwmaAnomalyDetector;
import com.plant.iq.detect.StatSignal;
import com.plant.iq.ingest.SensorReading;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

import java.util.List;

/** 断网时：边缘维持采集→检测→轻量决策本地闭环；网络恢复后增量同步（[调研 §断网续跑]） */
@Component
public class EdgeAutonomy {

    private final EwmaAnomalyDetector detector;
    private final LocalBuffer buffer;
    private final LocalAlarm localAlarm;
    private final CloudReachability reachability;
    private final UpstreamPublisher upstream;

    public EdgeAutonomy(EwmaAnomalyDetector detector, LocalBuffer buffer, LocalAlarm localAlarm,
                        CloudReachability reachability, UpstreamPublisher upstream) {
        this.detector = detector;
        this.buffer = buffer;
        this.localAlarm = localAlarm;
        this.reachability = reachability;
        this.upstream = upstream;
    }

    public void onReading(SensorReading r) {
        detector.onReading(r).ifPresent(signal -> {
            if (reachability.isReachable()) {
                upstream.publish(signal);          // 在线: 走云端
            } else {
                buffer.stash(signal);              // 断网: 本地缓冲
                edgeDecide(signal);                // 断网: 边缘自治决策
            }
        });
    }

    /** 断网时边缘自治决策：本地规则引擎（非 LLM）；z 超强阈值 → 本地告警 */
    private void edgeDecide(StatSignal signal) {
        if (signal.zScore() >= 6.0) {
            localAlarm.raise(signal.deviceId());
        }
    }

    @Scheduled(fixedDelay = 60_000)
    public void syncWhenReconnected() {
        if (reachability.isReachable() && !buffer.isEmpty()) {
            List<StatSignal> drained = buffer.drain();
            drained.forEach(upstream::publish);   // 恢复后 100% 增量同步
        }
    }
}
```

### 4.8 v4 改造点：`SensorIngestService.write` 走 `EdgeAutonomy`

```java
// v4 改造（完整可编译）：在 v1 SensorIngestService 基础上新增 EdgeAutonomy 字段，
// write() 的检测直发改为边缘自治路由（在线→云端 / 断网→本地缓冲+自治）。
// 原 v1 的 mapper/jdbc/detector/eventSink 字段与 parse()/构造器照旧保留，
// 此处将改动涉及的字段声明、构造器与 write()/childTable() 整段展开，一行不省略：
package com.plant.iq.ingest;

import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.plant.iq.edge.EdgeAutonomy;
import com.plant.iq.detect.EwmaAnomalyDetector;
import com.plant.iq.detect.AnomalyEventSink;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Service;

import java.sql.Timestamp;
import java.time.Instant;

@Service
public class SensorIngestService {

    private final ObjectMapper mapper;
    private final JdbcTemplate jdbc;
    private final EwmaAnomalyDetector detector;
    private final AnomalyEventSink eventSink;
    private final EdgeAutonomy edgeAutonomy;      // v4 新增

    public SensorIngestService(ObjectMapper mapper, JdbcTemplate jdbc,
                               EwmaAnomalyDetector detector, AnomalyEventSink eventSink,
                               EdgeAutonomy edgeAutonomy) {              // v4 构造器扩展
        this.mapper = mapper;
        this.jdbc = jdbc;
        this.detector = detector;
        this.eventSink = eventSink;
        this.edgeAutonomy = edgeAutonomy;
    }

    /** MQTT payload → SensorReading（设备发 JSON: {"deviceId":"pump-01","vibration":0.42,"temp":65.3}） */
    public SensorReading parse(String payload) {
        try {
            JsonNode node = mapper.readTree(payload);
            return new SensorReading(
                    node.get("deviceId").asText(),
                    node.get("vibration").asDouble(),
                    node.get("temp").asDouble(),
                    Instant.now());
        } catch (Exception e) {
            throw new IllegalArgumentException("MQTT payload 解析失败: " + payload, e);
        }
    }

    /** 写时序库 + 边缘自治路由（v1 的 detector.onReading + eventSink.emit 移入 EdgeAutonomy） */
    public void write(SensorReading r) {
        // TDengine 子表按设备自动创建；USING 绑定超表与 TAG
        jdbc.update("INSERT INTO " + childTable(r.deviceId())
                        + " USING sensor_reading TAGS (?) VALUES (?, ?, ?)",
                r.deviceId(),
                r.vibration(),
                r.temp(),
                Timestamp.from(r.ts()));

        edgeAutonomy.onReading(r);      // 边缘自治路由（替代 detector.onReading + eventSink.emit）
    }

    private String childTable(String deviceId) {
        return "sensor_" + deviceId.replaceAll("[^a-zA-Z0-9_]", "_");
    }
}
```

## 5. 本迭代的 ADR

### ADR 011-07：边缘 Ollama + 云端 vLLM 双引擎
- **决策**：统一 OpenAI 兼容接口 + `ModelTierRouter` 路由（常规→边缘，疑难→云端）
- **取舍理由**：边缘省成本/低延迟、断网自治；云端疑难会诊（[调研 §边缘部署]）

### ADR 011-08：断网边缘自治 + 增量同步
- **决策**：`EdgeAutonomy` 本地闭环（感知-决策-执行）+ `LocalBuffer` 落盘缓冲 + 恢复后增量同步
- **取舍理由**：产线停线不可容忍；本地闭环 + 恢复同步保证零丢失

### ADR 011-09：vLLM 用 AWQ 非 GGUF
- **决策**：云端 vLLM 量化格式选 AWQ
- **取舍理由**：vLLM 不支持 GGUF；AWQ 是质量最优 INT4（[调研 §边缘部署]）
