## 项目目标

你要做一个**命令行 AI 助手**，它能：

1. 多轮对话（记住上下文）
2. 查询时间、生成随机数
3. 做简单的数学计算
4. 读写本地文件

```
AI 助手 > 你好
AI：你好！有什么可以帮你的？

AI 助手 > 现在几点了
AI：现在是 2026-08-09 14:30:00 (Asia/Shanghai)

AI 助手 > 帮我算一下 123 * 456
AI：123 × 456 = 56088

AI 助手 > 把这个结果写到 result.txt
AI：已写入 result.txt

AI 助手 > 退出
再见！
```

### Step 2：数学工具

```java
package demo.demo01.tools;

import org.springframework.ai.tool.annotation.Tool;
import org.springframework.stereotype.Component;

@Component
public class MathTools {

    @Tool(description = "执行数学运算。expression 是数学表达式，如 '123 * 456' 或 '2 + 3 * 4'")
    public String calculate(String expression) {
        try {
            // 简化版：用 ScriptEngine 计算表达式
            // 生产环境应该用更安全的解析方式（阶段 3 讲安全）
            var engine = new javax.script.ScriptEngineManager().getEngineByName("js");
            if (engine == null) return "计算引擎不可用";

            Object result = engine.eval(expression);
            return expression + " = " + result;
        } catch (Exception e) {
            return "计算失败：" + e.getMessage() + "。请检查表达式格式。";
        }
    }
}
```

### Step 3：文件工具

```java
package demo.demo01.tools;

import org.springframework.ai.tool.annotation.Tool;
import org.springframework.stereotype.Component;

import java.nio.file.*;

@Component
public class FileTools {

    @Tool(description = "将内容写入文件。filename 是文件名，content 是要写入的内容")
    public String writeFile(String filename, String content) {
        try {
            Files.writeString(Path.of(filename), content);
            return "已成功写入文件：" + filename + "（" + content.length() + " 字符）";
        } catch (Exception e) {
            return "写入失败：" + e.getMessage();
        }
    }

    @Tool(description = "读取文件内容。filename 是要读取的文件名")
    public String readFile(String filename) {
        try {
            String content = Files.readString(Path.of(filename));
            // 限制返回长度，避免 token 浪费
            if (content.length() > 500) {
                content = content.substring(0, 500) + "\n...(截断，共 " + content.length() + " 字符)";
            }
            return content;
        } catch (Exception e) {
            return "读取失败：" + e.getMessage();
        }
    }
}
```

### Step 4：配置 ChatClient

```java
package demo.demo01.config;

import demo.demo01.tools.*;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.memory.*;
import org.springframework.context.annotation.*;

@Configuration
public class ChatConfig {

    @Bean
    public ChatMemory chatMemory() {
        return MessageWindowChatMemory.builder().maxMessages(20).build();
    }

    @Bean
    public ChatClient chatClient(
            ChatClient.Builder builder,
            ChatMemory memory,
            TimeTools timeTools,
            MathTools mathTools,
            FileTools fileTools) {

        return builder
                .defaultSystem("你是一个实用的命令行助手。帮助用户完成日常任务。回复简洁明了。")
                .defaultAdvisors(
                    MessageChatMemoryAdvisor.builder(memory).build()
                )
                .defaultTools(timeTools, mathTools, fileTools)
                .build();
    }
}
```

### Step 5：命令行交互

```java
package demo.demo01.cli;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.boot.CommandLineRunner;
import org.springframework.stereotype.Component;

import java.util.Scanner;
import java.util.UUID;

@Component
public class AssistantRunner implements CommandLineRunner {

    private final ChatClient chatClient;

    public AssistantRunner(ChatClient chatClient) {
        this.chatClient = chatClient;
    }

    @Override
    public void run(String... args) {
        var scanner = new Scanner(System.in);
        var sessionId = UUID.randomUUID().toString();  // 每次启动一个新会话

        System.out.println("═══════════════════════════════════");
        System.out.println("       AI 命令行助手 v1.0");
        System.out.println("═══════════════════════════════════");
        System.out.println("输入「退出」或「exit」结束对话\n");

        while (true) {
            System.out.print("你 > ");
            String input = scanner.nextLine().trim();

            if (input.isEmpty()) continue;
            if (input.equals("退出") || input.equalsIgnoreCase("exit")) {
                System.out.println("再见！");
                break;
            }

            try {
                System.out.print("AI > ");
                String reply = chatClient.prompt()
                        .user(input)
                        .advisors(spec -> spec.param(ChatMemory.CONVERSATION_ID, sessionId))
                        .call()
                        .content();
                System.out.println(reply);
                System.out.println();
            } catch (Exception e) {
                System.out.println("出错了：" + e.getMessage() + "\n");
            }
        }
    }
}
```

## 常见坑

- ❌ **ScriptEngine 不可用** → 某些 JDK 不自带 `js` 引擎。可以改用简单的 `Double.parseDouble` 或者引入 `exp4j` 库
- ❌ **文件路径问题** → 相对路径是相对于项目根目录的，注意你在哪里运行
- ❌ **工具太多导致 token 浪费** → 每个 `@Tool` 的描述都会占用 token。当前 3-5 个工具还好，多了就要阶段 3 的工具管理策略
