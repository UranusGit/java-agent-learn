# 04 · 进度追踪表——每周打卡，把计划变成现实

> **本份是什么**：本专题的执行工具。计划（03）写了 8 阶段，材料（05-11）写了知识——但**计划不打卡就是摆设**。这份表让你每周记录"做了什么 / 卡在哪 / 下周做什么"，每个阶段用验收标准自测。
>
> **怎么用**：每周复制一行到笔记里填写，或在文档里直接勾选。**每完成一个阶段，回 13 迭代检查报告更新覆盖状态。**
