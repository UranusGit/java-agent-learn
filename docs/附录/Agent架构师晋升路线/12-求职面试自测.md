# 12 · 求职面试自测——你在哪个水平？

> **本份是什么**：一套对应本专题 L1/L2/L3 三级里程碑的面试自测题。**不是背答案，是检验"你会不会用"**——每题能答出"为什么"才算过关。它同时是求职前的体检：哪组没过，回对应材料补强。
>
> **配套**：进度表（12）每个里程碑达成后用本份自测。全组答出 + 有可演示项目 = 可以面这一级。

---

## 0. 怎么用

1. 按 L1 → L2 → L3 顺序自测，**先别看复习指引**。
2. 答不出/说不清"为什么"的，标记下来，回对应材料（05-11）复习。
3. **全组答出 = 该级过关**；三组全过 + 加分题有见解 = 架构师水平，能面试、能带项目。

## 5. 行为/项目题（面试必问，准备你的故事）

1. **"讲一个你做的 Agent 项目。"** —— 用 STAR 结构：需求 → 我做的架构决策（为什么这么选）→ 量化结果（指标/成本）→ 我踩的坑和复盘。
2. **"你读过框架源码，讲一个印象深刻的实现。"** —— 选一个真实读过的（如 ToolCallingAdvisor 的循环收敛），讲清楚它解决什么问题、为什么这么设计。
3. **"你踩过最惨的一次 Agent 事故是什么？"** —— 复盘到根因（约束压错了哪个目标 / 缺了哪个护栏），而不是只描述现象。
4. **"你怎么评估你的 Agent 改得好不好？"** —— 必须答出"评估集 + 指标 + A/B 一次一变量"，否则扣分。

> 准备技巧：把 P1-P5 每个项目的**架构决策 + 量化指标 + 踩坑复盘**写成 3-5 个可复用的故事。面试官要的不是完美，是"真实 + 会复盘"。
