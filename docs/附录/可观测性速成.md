## 什么是可观测性

可观测性（Observability）是**从系统外部行为推断系统内部状态**的能力。传统监控只告诉你"系统挂了"，可观测性告诉你"为什么挂了"。

## Metrics（指标）

| 类型 | 示例 | 用途 |
|------|------|------|
| **Counter（计数器）** | 总请求数、总错误数 | 统计总量和速率 |
| **Gauge（计量器）** | 当前并发数、队列深度 | 反映当前状态 |
| **Histogram（直方图）** | 延迟分布、Token 消耗分布 | 分析分布和百分位 |
| **Summary（摘要）** | P50/P95/P99 延迟 | 直接读百分位 |

## Traces（链路追踪）

```mermaid
sequenceDiagram
    participant U as 用户
    participant API as API层
    participant ADV as Advisor链
    participant LLM as LLM调用
    participant TOOL as 工具执行
    participant VDB as 向量检索

    U->>API: 发送消息
    Note over API: span: session.start
    
    API->>ADV: 请求经过Advisor链
    Note over ADV: span: advisor_chain
    
    ADV->>VDB: RAG检索
    Note over VDB: span: vector_search (45ms)
    VDB-->>ADV: 返回5个文档

    ADV->>LLM: 第一次LLM调用
    Note over LLM: span: llm.call#1 (1.2s, 500→200 tokens)
    LLM-->>ADV: 工具调用请求

    ADV->>TOOL: 执行工具queryDB
    Note over TOOL: span: tool.call:queryDB (230ms)
    TOOL-->>ADV: 查询结果

    ADV->>LLM: 第二次LLM调用
    Note over LLM: span: llm.call#2 (800ms, 800→150 tokens)
    LLM-->>ADV: 最终回答

    ADV-->>API: 响应
    Note over API: span: session.end (总2.8s)
    API-->>U: 流式返回
```

### Span 属性设计

```java
// 每个 Span 应记录的关键属性
Span span = tracer.nextSpan().name("llm.call").start();
span.tag("llm.model", "claude-sonnet-5");
span.tag("llm.input.tokens", "500");
span.tag("llm.output.tokens", "200");
span.tag("llm.cost.usd", "0.003");
span.tag("llm.ttft.ms", "280");  // 首 Token 延迟
span.tag("llm.tool_calls", "1");
span.end();
```

## 采样策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 全量采样 | 100% Trace 记录 | 开发/测试环境 |
| 头部采样 | 前N%请求记录 | 低流量生产 |
| 尾部采样 | 错误/慢请求100%，正常请求1% | 高流量生产（推荐） |
| 智能采样 | 基于内容质量/异常模式采样 | Agent 系统（进阶） |

> **Agent 特殊采样**：优先采样低质量输出、高成本请求、安全告警触发的会话。
