> **文档规模**：82 篇文档，持续扩充至 103 篇目标体系。

## 阅读路线推荐

### 路线一：初学者路线（约 10-15 小时）

适合刚接触 AI Agent 的 Java 开发者，从零开始构建第一个 Agent。

```
教程/00-Agent核心概念
    ↓
教程/01-Spring-AI框架入门
    ↓
教程/02-ChatClient与对话模型
    ↓
教程/03-工具调用
    ↓
教程/04-记忆与会话管理
    ↓
教程/05-RAG检索增强生成
    ↓
项目/00-智能客服系统（全部 6 篇）
```

**目标**：完成智能客服系统项目，掌握 Agent 的核心骨架——ChatClient + 工具 + 记忆 + RAG。

### 路线二：架构师路线（约 40-60 小时）

适合需要设计和落地企业级 Agent 系统的架构师，全面覆盖。

```
第一遍：全部教程（00-40）           ← 通读 41 篇，建立知识体系
    ↓
第二遍：全部项目（00-03）            ← 4 个实战项目，验证理论
    ↓
第三遍：关键附录
    ├── 附录/00-Java21新特性          ← 虚拟线程、Record、密封类
    ├── 附录/01-WebFlux与响应式编程   ← Reactor、背压
    ├── 附录/02-Prompt工程            ← 设计模式、注入防御
    ├── 附录/03-Spring-AI源码解析     ← 深入框架内部
    └── 附录/04-测试策略              ← 单元/集成测试
    ↓
第四遍：前沿调研（全部 7 篇）          ← 拓展视野，规划技术路线
```

**目标**：具备从零设计企业级 Agent 系统的完整能力，涵盖架构、安全、可观测性、成本治理。

### 路线三：速查路线（约 3-5 小时）

适合有 AI 开发经验、需要快速查阅关键实践的工程师。

```
教程/40-Agent架构反模式与避坑指南     ← 先看避坑清单，避免踩雷
    ↓
教程/14-管控分离架构                  ← 理解数据面/控制面分离核心架构
    ↓
教程/16-全链路可观测性                ← 生产级 Agent 的眼睛
    ↓
按需查阅下方索引表中的具体章节
```

**目标**：快速建立架构质量检查意识，知道"什么该做、什么不该做"。
