## 审计日志设计

```java
@Component
public class AuditAdvisor implements BaseAdvisor {

    // append-only：只插入不修改不删除
    private final AuditLogRepository auditRepo;

    @Override
    public ChatClientResponse after(ChatClientResponse response) {
        AuditLog log = AuditLog.builder()
            .timestamp(Instant.now())
            .tenantId(TenantContext.get())
            .userId(SecurityContext.getUserId())
            .sessionId(sessionId)
            .prompt(redactedPrompt)          // prompt（脱敏后）
            .reply(response.content())       // reply
            .model(response.model())
            .inputTokens(usage.getPromptTokens())
            .outputTokens(usage.getCompletionTokens())
            .toolsCalled(getToolsCalled(response))  // 调用了哪些工具
            .build();

        auditRepo.save(log);  // append-only
        return response;
    }
}
```

> EU AI Act Article 12 要求：高风险 AI 系统必须保留自动日志记录，且日志是 append-only 的。
