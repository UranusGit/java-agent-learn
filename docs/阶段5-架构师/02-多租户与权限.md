## 多租户隔离模式

| 模式 | 隔离强度 | 复杂度 | 适用 |
|------|---------|--------|------|
| 行级（共享表 + tenant_id 列） | 低 | 低 | 中小规模 |
| Schema 级（每租户独立 Schema） | 中 | 中 | 中等规模 |
| 数据库级（每租户独立 DB） | 高 | 高 | 大客户/合规 |

**AI 应用的特殊隔离**：不只是数据库——向量库也要隔离（每个租户的知识库不能混）。

```java
// 行级隔离：所有查询都带上 tenantId
@Tool(description = "查询知识库")
public String search(String query) {
    String tenantId = TenantContext.get();  // 从 ThreadLocal/Reactor Context 获取
    return vectorStore.similaritySearch(
        SearchRequest.builder()
            .query(query)
            .filterExpression("tenant_id == '" + tenantId + "'")  // ← 关键！
            .topK(3)
            .build()
    );
}
```

## 上下文透传

```java
// 每个 HTTP 请求提取 tenantId → 存入 Reactor Context → 所有 Advisor/Tool 可见
@Component
public class TenantAdvisor implements BaseAdvisor {

    @Override
    public ChatClientRequest before(ChatClientRequest request) {
        String tenantId = request.context().get("tenantId");
        // 把 tenantId 注入 system prompt
        String systemWithTenant = request.prompt()
            + "\n[当前租户：" + tenantId + "]";
        return request.mutate().prompt(systemWithTenant).build();
    }
}
```
