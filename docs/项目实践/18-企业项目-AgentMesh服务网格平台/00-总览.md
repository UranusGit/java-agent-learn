# ⑱ AgentMesh — Agent 服务网格与 Sidecar 平台

> **代号**：AgentMesh
> **核心问题**：50 个 Agent 互相调用，限流/熔断/追踪/加密散落在各处——用服务网格统一治理。

---

## 项目定位

```mermaid
flowchart TD
    Problem["痛点"] --> P1["每个 Agent 自己写限流/重试<br/>代码重复"]
    Problem --> P2["Agent 间调用无追踪<br/>故障难定位"]
    Problem --> P3["无统一安全策略<br/>mTLS 难落地"]
    Problem --> P4["流量调度分散<br/>无法统一灰度"]

    Solution["AgentMesh"] --> S1["Sidecar 代理<br/>统一限流/熔断/重试"]
    Solution --> S2["分布式追踪<br/>全链路可视化"]
    Solution --> S3["mTLS 加密<br/>自动证书管理"]
    Solution --> S4["流量治理<br/>统一灰度/路由"]

    style Solution fill:#4caf50,color:#fff
```

## 技术栈

| 层 | 技术 |
|----|------|
| Sidecar | Envoy / 自研 Java Proxy |
| 控制面 | Spring Boot + Consul/etcd |
| 追踪 | OpenTelemetry + Jaeger |
| 监控 | Prometheus + Grafana |
| 部署 | Kubernetes + Sidecar Injection |
