# ⑰ GraphRAG Pro — 知识图谱与 GraphRAG 平台

> **代号**：GraphRAG Pro
> **核心问题**：纯向量 RAG 只能做"相似度匹配"，无法做多跳推理和关系查询——企业知识库需要更强。

---

## 项目定位

```mermaid
flowchart TD
    Problem["纯向量 RAG 局限"] --> P1["无法多跳推理<br/>'A的同事的项目'"]
    Problem --> P2["无法关系查询<br/>'A和B的关系'"]
    Problem --> P3["无法聚合统计<br/>'多少人参与'"]

    Solution["GraphRAG Pro"] --> S1["知识图谱构建<br/>文档→实体→关系"]
    Solution --> S2["混合检索<br/>向量+图谱+BM25"]
    Solution --> S3["多跳推理<br/>Cypher查询生成"]
    Solution --> S4["图谱可视化<br/>交互式探索"]

    style Solution fill:#4caf50,color:#fff
```

```mermaid
flowchart LR
```

| Sprint | 目标 | V1→V2→V3 | 时间 |
|--------|------|---------|------|
| Sprint 1 | 图谱构建 | V1 LLM抽取 → V2 实体消歧 → V3 增量更新 | 1.5 周 |
| Sprint 2 | 混合检索 | V1 串行检索 → V2 并行融合 → V3 自适应路由 | 1 周 |
| Sprint 3 | 多跳推理 | V1 单跳 → V2 多跳 → V3 复杂聚合 | 1 周 |
| Sprint 4 | 可视化 | V1 图谱浏览 → V2 查询可视化 → V3 编辑 | 1 周 |

## 架构设计

```mermaid
flowchart TD
    Docs["原始文档"] --> Extract["实体关系抽取"]
    Extract --> Graph["知识图谱<br/>Neo4j"]
    Docs --> Chunk["分块+Embedding"]
    Chunk --> Vector["向量库<br/>PgVector"]

    Query["用户查询"] --> Classifier{"查询分类"}
    Classifier -->|"事实型"| Vec["向量检索"]
    Classifier -->|"关系型"| Graph2["图谱查询"]
    Classifier -->|"多跳型"| Hybrid["混合检索"]

    Vec --> Merge["结果融合"]
    Graph2 --> Merge
    Hybrid --> Merge
    Merge --> LLM["LLM 生成回答"]

    style Graph fill:#4caf50,color:#fff
    style Merge fill:#2196f3,color:#fff
```
