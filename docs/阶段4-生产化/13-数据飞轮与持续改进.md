## 什么是数据飞轮

**数据飞轮（Data Flywheel）** 是一个自我强化的闭环系统：Agent 在生产中运行 → 产生交互数据 → 从中提取高质量样本 → 用这些样本改进模型/Prompt → Agent 变得更好 → 吸引更多用户 → 产生更多数据。

```mermaid
cycle
    P["🚀 生产运行<br/>Agent 服务用户"] --> D["📊 数据采集<br/>对话+反馈+行为"]
    D --> C["🔍 质量筛选<br/>好样本/坏样本"]
    C --> E["📋 评估集更新<br/>Golden Set 扩充"]
    E --> I["🔧 改进<br/>Prompt/Fine-tune/RAG"]
    I --> T["✅ 评估验证<br/>新版本 vs 旧版本"]
    T --> R["🚢 发布<br/>更好的 Agent"]
    R --> P
```

> 核心洞察（来自 NVIDIA GTC 2025）：**有效的 AI Agent 不需要"下一个更大的 LLM"，需要的是数据飞轮——让生产数据驱动持续改进。**

## 四阶段飞轮架构

### 阶段 1：数据采集

```java
package com.example.flywheel;

import org.springframework.stereotype.Component;
import java.util.*;

/**
 * 交互数据采集器
 *
 * 采集每个用户交互的多维度信号：
 * - 对话内容
 * - 用户显式反馈（👍/👎/评分）
 * - 用户隐式反馈（重试/复制/编辑/停留时长）
 * - 工具调用结果
 * - 系统指标（延迟/token/成本）
 */
@Component
public class InteractionCollector {

    private final InteractionRepository repository;

    /**
     * 记录一次完整的 Agent 交互
     */
    public void record(InteractionRecord record) {
        repository.save(record);
    }

    /**
     * 记录用户反馈
     */
    public void recordFeedback(String interactionId, Feedback feedback) {
        repository.updateFeedback(interactionId, feedback);
    }

    public record InteractionRecord(
        String id,
        String tenantId,
        String sessionId,
        String userInput,
        String agentResponse,
        List<ToolCallRecord> toolCalls,
        String modelUsed,
        long latencyMs,
        int inputTokens,
        int outputTokens,
        Feedback explicitFeedback,    // 用户显式反馈
        ImplicitSignals implicitSignals, // 隐式信号
        Instant timestamp
    ) {}

    public record Feedback(
        Rating rating,        // THUMBS_UP/DOWN, 1-5 STAR
        String comment,
        String category       // "correct_answer" / "wrong_answer" / "too_slow" / "inappropriate"
    ) {}

    public enum Rating {
        THUMBS_UP, THUMBS_DOWN, ONE_STAR, TWO_STARS, THREE_STARS, FOUR_STARS, FIVE_STARS
    }

    /**
     * 隐式反馈信号——用户不需要主动操作
     */
    public record ImplicitSignals(
        boolean userRetried,       // 用户是否重新问了同样的问题
        boolean userCopied,        // 用户是否复制了回复
        boolean userEdited,        // 用户是否编辑了回复后才使用
        long timeOnResponse,       // 用户看回复的停留时长（秒）
        boolean sessionAbandoned,  // 用户是否放弃了会话
        int followupQuestions      // 后续追问次数（多=可能没回答好）
    ) {}

    public record ToolCallRecord(
        String toolName, boolean success, long latencyMs, String errorMessage
    ) {}
}
```

### 阶段 2：质量筛选

```java
package com.example.flywheel;

import org.springframework.stereotype.Component;
import java.util.stream.*;

/**
 * 质量筛选器
 *
 * 从所有交互中筛选出有价值的样本：
 * - 正样本：用户满意 + 事实正确 → 可以作为 Few-shot 示例
 * - 负样本：用户不满意 + 有明确问题 → 用于改进
 * - 边界样本：有争议的 → 需要人工标注
 */
@Component
public class QualityFilter {

    private final InteractionRepository repository;
    private final LlmEvaluator llmEvaluator; // 用 LLM 做自动评估

    /**
     * 每日批量筛选
     */
    @Scheduled(cron = "0 0 2 * * *") // 每天凌晨 2 点
    public void dailyFiltering() {
        Instant yesterday = Instant.now().minus(1, ChronoUnit.DAYS);
        List<InteractionRecord> interactions = repository
            .findByTimeRange(yesterday, Instant.now());

        // 自动分类
        List<QualitySample> samples = interactions.stream()
            .map(this::classify)
            .filter(Objects::nonNull)
            .toList();

        // 写入样本库
        samples.forEach(sampleRepository::save);

        // 通知评估集更新
        eventBus.publish(new SamplesReady(samples));
    }

    /**
     * 自动分类一个交互
     */
    private QualitySample classify(InteractionRecord interaction) {
        // 1. 显式反馈优先
        if (interaction.explicitFeedback() != null) {
            Rating r = interaction.explicitFeedback().rating();
            if (r == Rating.THUMBS_UP || r == Rating.FIVE_STARS || r == Rating.FOUR_STARS) {
                return QualitySample.positive(interaction, "user_thumbs_up");
            }
            if (r == Rating.THUMBS_DOWN || r == Rating.ONE_STAR || r == Rating.TWO_STARS) {
                return QualitySample.negative(interaction, "user_thumbs_down");
            }
        }

        // 2. 隐式信号判断
        ImplicitSignals signals = interaction.implicitSignals();
        if (signals != null) {
            // 用户重试了 → 可能回答不好
            if (signals.userRetried()) {
                return QualitySample.negative(interaction, "user_retried");
            }
            // 用户复制了 → 可能回答好
            if (signals.userCopied() && !signals.userEdited()) {
                return QualitySample.positive(interaction, "user_copied");
            }
            // 用户放弃了会话 → 可能回答很差
            if (signals.sessionAbandoned()) {
                return QualitySample.negative(interaction, "session_abandoned");
            }
        }

        // 3. LLM 自动评估（对没有明确反馈的交互）
        EvaluationResult eval = llmEvaluator.evaluate(interaction);
        if (eval.score() >= 0.85) {
            return QualitySample.positive(interaction, "llm_eval_high");
        }
        if (eval.score() <= 0.4) {
            return QualitySample.negative(interaction, "llm_eval_low");
        }

        // 4. 边界样本——需要人工标注
        if (eval.score() > 0.4 && eval.score() < 0.85) {
            return QualitySample.boundary(interaction, "needs_human_review");
        }

        return null; // 不纳入样本
    }

    public record QualitySample(
        String interactionId,
        SampleType type,        // POSITIVE / NEGATIVE / BOUNDARY
        String reason,          // 分类原因
        InteractionRecord interaction,
        Instant sampledAt
    ) {
        static QualitySample positive(InteractionRecord i, String reason) {
            return new QualitySample(i.id(), SampleType.POSITIVE, reason, i, Instant.now());
        }
        static QualitySample negative(InteractionRecord i, String reason) {
            return new QualitySample(i.id(), SampleType.NEGATIVE, reason, i, Instant.now());
        }
        static QualitySample boundary(InteractionRecord i, String reason) {
            return new QualitySample(i.id(), SampleType.BOUNDARY, reason, i, Instant.now());
        }
    }

    public enum SampleType { POSITIVE, NEGATIVE, BOUNDARY }
}
```

### 阶段 3：评估集管理

```java
package com.example.flywheel;

import org.springframework.stereotype.Component;
import java.util.*;

/**
 * Golden Set 管理器
 *
 * 维护一个高质量的评估数据集：
 * - 从每日样本中挑选最有代表性的
 * - 人工审核后纳入 Golden Set
 * - 每次改版后用 Golden Set 回归测试
 */
@Component
public class GoldenSetManager {

    private final GoldenSetRepository repository;

    /**
     * 提交候选样本（等待人工审核）
     */
    public void submitCandidate(QualityFilter.QualitySample sample) {
        repository.saveCandidate(new GoldenSetCandidate(
            UUID.randomUUID().toString(),
            sample,
            ReviewStatus.PENDING,
            null, // reviewer
            null  // reviewedAt
        ));
    }

    /**
     * 人工审核
     */
    public void review(String candidateId, ReviewDecision decision,
                       String reviewerNotes) {
        GoldenSetCandidate candidate = repository.findCandidate(candidateId);

        if (decision == ReviewDecision.ACCEPT) {
            // 纳入 Golden Set
            GoldenSetItem item = new GoldenSetItem(
                candidateId,
                candidate.sample().interaction().userInput(),
                candidate.sample().interaction().agentResponse(),
                candidate.sample().type(),
                candidate.sample().reason(),
                reviewerNotes,
                Instant.now()
            );
            repository.saveToGoldenSet(item);
        }

        repository.markReviewed(candidateId, decision, reviewerNotes);
    }

    /**
     * 用 Golden Set 回归测试
     */
    public RegressionResult runRegression(ChatClient newVersionClient) {
        List<GoldenSetItem> goldenSet = repository.getGoldenSet();
        int pass = 0, fail = 0;
        List<String> failures = new ArrayList<>();

        for (GoldenSetItem item : goldenSet) {
            // 用新版本重新生成回答
            String newResponse = newVersionClient.prompt()
                .user(item.userInput())
                .call()
                .content();

            // 用 LLM 做裁判评分
            double score = llmJudge.compare(item.expectedOutput(), newResponse);

            if (score >= 0.8) {
                pass++;
            } else {
                fail++;
                failures.add(String.format(
                    "FAIL [%s]: expected=%s, got=%s, score=%.2f",
                    item.id(), item.expectedOutput().substring(0, 50),
                    newResponse.substring(0, 50), score
                ));
            }
        }

        return new RegressionResult(pass, fail, goldenSet.size(), failures);
    }

    public record GoldenSetItem(
        String id, String userInput, String expectedOutput,
        QualityFilter.SampleType type, String reason,
        String reviewerNotes, Instant addedAt
    ) {}

    public enum ReviewStatus { PENDING, ACCEPTED, REJECTED }
    public enum ReviewDecision { ACCEPT, REJECT }
    public record RegressionResult(int pass, int fail, int total, List<String> failures) {
        public double passRate() { return (double) pass / total; }
        public boolean passed() { return passRate() >= 0.95; }
    }
}
```

### 阶段 4：持续改进

```java
package com.example.flywheel;

import org.springframework.stereotype.Component;
import java.util.*;

/**
 * 持续改进引擎
 *
 * 基于负样本自动生成改进建议：
 * - Prompt 补丁（"你在 X 类问题上经常出错，原因是 Y"）
 * - Few-shot 示例（把正样本加到 Prompt 中）
 * - 工具修复（某个工具频繁失败→需要修复）
 */
@Component
public class ContinuousImprovementEngine {

    /**
     * 生成改进报告
     */
    public ImprovementReport generateReport(List<QualityFilter.QualitySample> negativeSamples) {
        // 按错误模式聚类
        Map<String, List<QualityFilter.QualitySample>> clusters = negativeSamples.stream()
            .collect(Collectors.groupingBy(this::classifyErrorPattern));

        List<ImprovementSuggestion> suggestions = new ArrayList<>();

        // 工具调用失败 → 修复工具
        if (clusters.containsKey("tool_failure")) {
            suggestions.add(new ImprovementSuggestion(
                SuggestionType.TOOL_FIX,
                "工具调用失败率过高",
                "以下工具频繁失败：" + extractFailingTools(clusters.get("tool_failure")),
                Priority.HIGH
            ));
        }

        // 答非所问 → 补充 Prompt
        if (clusters.containsKey("wrong_answer")) {
            suggestions.add(new ImprovementSuggestion(
                SuggestionType.PROMPT_PATCH,
                "存在系统性错误回答",
                "建议在 System Prompt 中补充以下约束：" +
                    extractCommonMistakes(clusters.get("wrong_answer")),
                Priority.HIGH
            ));
        }

        // 回复太长 → 调整 Prompt
        if (clusters.containsKey("too_verbose")) {
            suggestions.add(new ImprovementSuggestion(
                SuggestionType.PARAMETER_ADJUST,
                "回复过长",
                "建议在 Prompt 中增加简洁性约束，或降低 max_tokens",
                Priority.MEDIUM
            ));
        }

        // 好的正样本 → 加为 Few-shot 示例
        suggestions.add(new ImprovementSuggestion(
            SuggestionType.ADD_FEW_SHOT,
            "从正样本中提取 Few-shot 示例",
            "以下高质量回答可作为 Few-shot 示例加入 Prompt",
            Priority.LOW
        ));

        return new ImprovementReport(suggestions, clusters.size(), negativeSamples.size());
    }

    private String classifyErrorPattern(QualityFilter.QualitySample sample) {
        // 简化的分类逻辑
        InteractionRecord r = sample.interaction();
        boolean hasToolFailure = r.toolCalls().stream()
            .anyMatch(t -> !t.success());
        if (hasToolFailure) return "tool_failure";
        if (r.implicitSignals() != null && r.implicitSignals().followupQuestions() > 3)
            return "wrong_answer";
        if (r.outputTokens() > 2000) return "too_verbose";
        return "other";
    }

    public record ImprovementReport(
        List<ImprovementSuggestion> suggestions,
        int patternCount, int totalNegatives
    ) {}

    public record ImprovementSuggestion(
        SuggestionType type, String title, String detail, Priority priority
    ) {}

    public enum SuggestionType {
        PROMPT_PATCH,      // 修改 Prompt
        ADD_FEW_SHOT,      // 加 Few-shot 示例
        TOOL_FIX,          // 修复工具
        PARAMETER_ADJUST,  // 调整参数
        DATA_AUGMENT       // 数据增强
    }

    public enum Priority { HIGH, MEDIUM, LOW }
}
```

## MAPE 控制环（学术前沿）

> 来自 arXiv:2510.27.051 ——将经典控制论的 MAPE（Monitor→Analyze→Plan→Execute）应用于 Agent 数据飞轮。

| MAPE 阶段 | 在 Agent 飞轮中的实现 |
|-----------|-------------------|
| **M**onitor | 实时采集交互数据 + 用户反馈 |
| **A**nalyze | 质量筛选 + 错误模式聚类 + LLM 自动评估 |
| **P**lanning | 生成改进建议（Prompt 补丁/Few-shot/工具修复） |
| **E**xecute | 应用改进 → 回归测试 → 灰度发布 |
