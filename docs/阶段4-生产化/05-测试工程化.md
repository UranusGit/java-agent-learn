## 四层测试体系

| 层级 | 测什么 | 工具 | 频率 |
|------|--------|------|------|
| 单元测试 | 单个方法逻辑（工具/Advisor） | JUnit + Mockito | 每次提交 |
| 集成测试 | 组件间协作（Spring 上下文） | Testcontainers | 每次 PR |
| Eval 测试 | AI 输出质量（评估集回归） | Promptfoo / 自研 | 每次 PR |
| 契约测试 | API 稳定性（Mock LLM 响应） | WireMock | 每次提交 |

## 核心实践

### Mock LLM 的单元测试

```java
@MockBean ChatClient chatClient;

@Test
void testRagSearch() {
    // Mock LLM 响应（不真实调用 API）
    when(chatClient.prompt().user(anyString()).call().content())
        .thenReturn("根据文档，报销流程是...");

    String result = ragController.ask("报销流程");
    assertThat(result).contains("报销");
}
```

### Eval 回归测试

```java
@Test
void evalRegression() {
    // 每次改动后跑评估集——指标不能退化
    var result = evaluator.evaluate(TestSet.buildDefault());
    assertThat(result.recallAt5()).isGreaterThanOrEqualTo(0.80);
    assertThat(result.faithfulness()).isGreaterThanOrEqualTo(0.75);
}
```

## 四层测试的实战示例

### 第 1 层：单元测试（Mock LLM，不花钱）

```java
@SpringBootTest
class ToolTest {

    @MockBean ChatClient.Builder chatClientBuilder;
    @MockBean ChatClient chatClient;

    @Autowired TimeTools timeTools;

    @Test
    void testGetCurrentTime_Beijing() {
        String result = timeTools.getCurrentTime("北京");
        assertThat(result).contains("北京");
        assertThat(result).contains("Asia/Shanghai");
    }

    @Test
    void testGetCurrentTime_InvalidCity() {
        String result = timeTools.getCurrentTime("火星");
        // 应该返回 UTC 而不是崩溃
        assertThat(result).contains("UTC");
    }
}
```

### 第 2 层：集成测试（Testcontainers + 真实组件）

```java
@SpringBootTest
@Testcontainers
class RagIntegrationTest {

    @Container
    static GenericContainer<?> redis = new GenericContainer<>("redis:7-alpine")
            .withExposedPorts(6379);

    @Test
    void testRagUploadAndSearch() {
        // 上传 PDF → 检索 → 验证结果
        int chunks = ragService.ingestPdf(testPdfResource);
        assertThat(chunks).isGreaterThan(0);

        var docs = ragService.search("报销流程", 3);
        assertThat(docs).isNotEmpty();
        assertThat(docs.get(0).getText()).containsAnyOf("报销", "发票", "审批");
    }
}
```

### 第 3 层：Eval 回归（质量不退化）

```java
@Test
void evalRegression_recallNotDegraded() {
    var result = evaluator.evaluate(TestSet.buildDefault());
    // 基线 Recall@5 = 0.83，不允许退化超过 5%
    assertThat(result.recallAt5())
        .as("Recall@5 不应退化").isGreaterThanOrEqualTo(0.78);
}

@Test
void evalRegression_faithfulnessNotDegraded() {
    var result = evaluator.evaluate(TestSet.buildDefault());
    // 基线 Faithfulness = 0.76
    assertThat(result.faithfulness())
        .as("Faithfulness 不应退化").isGreaterThanOrEqualTo(0.71);
}
```

### 第 4 层：契约测试（WireMock 模拟 LLM API）

```java
@SpringBootTest
class LlmContractTest {

    @RegisterExtension
    static WireMockExtension wm = WireMockExtension.newInstance()
            .options(wireMockConfig().dynamicPort()).build();

    @Test
    void testChatClientHandlesLlmResponseFormat() {
        // 模拟 LLM 返回的标准 JSON 格式
        wm.stubFor(post(urlEqualTo("/v1/chat/completions"))
            .willReturn(okJson("""
                {"choices": [{"message": {"content": "你好！"}}],
                 "usage": {"prompt_tokens": 5, "completion_tokens": 3, "total_tokens": 8}}
                """)));

        // 验证你的代码能正确解析
        String reply = chatClient.prompt().user("你好").call().content();
        assertThat(reply).isEqualTo("你好！");
    }

    @Test
    void testChatClientHandlesLlmError() {
        // 模拟 LLM 返回 429（限流）
        wm.stubFor(post(urlEqualTo("/v1/chat/completions"))
            .willReturn(aResponse().withStatus(429).withBody("Rate limited")));

        // 验证你的错误处理逻辑
        assertThatThrownBy(() -> chatClient.prompt().user("test").call().content())
            .isInstanceOf(RuntimeException.class);
    }
}
```

## 测试覆盖率目标

| 层级 | 覆盖目标 | 频率 | CI 时间 |
|------|---------|------|---------|
| 单元测试 | 80%+ | 每次提交 | < 30s |
| 集成测试 | 核心流程 100% | 每次 PR | 1-3 min |
| Eval 回归 | 评估集 100% | 每次 PR | 3-10 min |
| 契约测试 | API 格式 100% | 每次提交 | < 10s |

> **CI 中的 Eval 门禁**：PR 的 eval 指标不能低于 main 分支的 95%。退化超 5% 自动 block PR。

## 随堂练习：Eval 回归测试套件（60 分钟）

为翻译接口搭建评估回归：测试集 → 自动跑 → 生成报告 → CI 门禁。

**提示**：定义 9 条翻译测试用例（基础 + 长句 + 术语 + 边界），用关键词匹配判断通过/失败，计算通过率。

**验收**：评估集 > 9 条；通过率统计正确；有 CI 门禁配置（通过率 < 80% 时 block PR）。
