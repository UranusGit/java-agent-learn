## 四层测试体系

| 层级 | 测什么 | 工具 | 频率 |
|------|--------|------|------|
| 单元测试 | 单个方法逻辑（工具/Advisor） | JUnit + Mockito | 每次提交 |
| 集成测试 | 组件间协作（Spring 上下文） | Testcontainers | 每次 PR |
| Eval 测试 | AI 输出质量（评估集回归） | Promptfoo / 自研 | 每次 PR |
| 契约测试 | API 稳定性（Mock LLM 响应） | WireMock | 每次提交 |

---

## 核心实践

### Mock LLM 的单元测试

```java
@MockBean ChatClient chatClient;

@Test
void testRagSearch() {
    // Mock LLM 响应（不真实调用 API）
    when(chatClient.prompt().user(anyString()).call().content())
        .thenReturn("根据文档，报销流程是...");

    String result = ragController.ask("报销流程");
    assertThat(result).contains("报销");
}
```

### Eval 回归测试

```java
@Test
void evalRegression() {
    // 每次改动后跑评估集——指标不能退化
    var result = evaluator.evaluate(TestSet.buildDefault());
    assertThat(result.recallAt5()).isGreaterThanOrEqualTo(0.80);
    assertThat(result.faithfulness()).isGreaterThanOrEqualTo(0.75);
}
```
