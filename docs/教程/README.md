# 教程（主线学习）

> **这是主线代码教程**：先动手，再补理论。所有文件**扁平**存放，按「系列前缀 + 编号」分组。
> 学习主线：**LangChain4j 入门 → Spring AI 2.0 主线 → Agent 进阶**。
> 概念卡壳 → 去 `理论/`；底层背景卡壳 → 去 `附录/`。

| 前缀 | 系列 | 篇数 | 定位 | 入口 |
