# pie / mindmap / timeline / journey

这几类语法简单，但**缩进或引号敏感**，写错整图不渲染。

## pie（饼图）

````markdown
```mermaid
pie title 技术栈占比
    "Java" : 60
    "Python" : 25
    "其他" : 15
```
````

- `pie` 后跟 `title 标题`（可选）。
- 每行 `"标签" : 数值`，**标签必须加引号**，数值不带单位。
- 注释：`%%`。

## mindmap（思维导图）

````markdown
```mermaid
mindmap
  root((技术栈))
    后端
      Java
      Spring Boot
    前端
      Vue
    数据库
      MySQL
      Redis
```
````

- 关键字 `mindmap`，**严格按缩进定义层级**（缩进越深层级越低，建议统一用两个空格）。
- 根节点写法 `root((标题))`；`root` 可以省略但建议保留。
- 子节点可加形状后缀：`( )` 圆角、`[ ]` 矩形、`(( ))` 圆形、`{ }` 菱形、`[/ /]` 平行四边形。
- 节点文本含特殊字符时加引号：`"Java (JDK 21)"`。
- 缩进层级必须一致，混用 2 空格和 4 空格会导致层级错乱。

## timeline（时间线）

````markdown
```mermaid
timeline
    title 项目里程碑
    2026-Q1 : 需求确认
    2026-Q2 : 开发完成
         : 联调测试
    2026-Q3 : 正式上线
```
````

- 格式：`时期 : 事件`；同一时期多个事件，后续事件行要**更深的缩进**并写 `: 事件`。
- 时期和事件文本含 `:` 时注意别拆错，特殊字符加引号。
- **timeline 对缩进非常挑剔**：时期行和事件行的缩进必须能区分层级，否则渲染报错。拿不准就写成单个事件一行。

## journey（旅程图）

````markdown
```mermaid
journey
    title 用户注册旅程
    section 注册
        打开注册页: 5: 我
        填写表单: 3: 我
        提交审核: 2: 我
    section 审核
        等待结果: 4: 我, 管理员
```
````

- `section 阶段` 分组；每行 `任务: 评分(0-5): 角色`，角色可多个用逗号分隔。
- 评分在 0-5 之间，影响竖条长度。

## 常见坑

- **四类图的共性**：缩进是语法的一部分，生成后检查缩进是否一致、根节点是否在 `mindmap` 下一行。
- pie 的标签不加引号会在含空格时出错；mindmap / timeline / journey 同理。
