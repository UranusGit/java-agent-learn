# gantt（甘特图）

画项目排期、任务依赖、里程碑。技术文档里的实施计划、迭代安排用。

## 基础模板

````markdown
```mermaid
gantt
    title 项目排期
    dateFormat YYYY-MM-DD
    axisFormat %m-%d
    excludes weekends

    section 阶段一
        需求分析  :a1, 2026-08-01, 5d
        方案设计  :a2, after a1, 5d
    section 阶段二
        开发实现  :a3, after a2, 10d
        测试验收  :a4, after a3, 5d
        上线发布  :milestone m1, 2026-08-30, 0d
```
````

## 关键配置

| 配置 | 说明 |
|---|---|
| `dateFormat YYYY-MM-DD` | 日期格式（`YYYY-MM-DD` 最常用） |
| `axisFormat %m-%d` | 横轴刻度显示格式 |
| `excludes weekends` | 跳过周末；或 `excludes 2026-08-01,2026-08-08` 指定日期 |
| `title 标题` | 图标题（第一行） |

## 任务写法

- 格式：`任务名 :任务ID, 开始, 时长`
- 开始可以是具体日期：`:a1, 2026-08-01, 5d`
- 也可以依赖前一任务：`:a2, after a1, 5d`（`a1` 是上一个任务的 ID）
- 时长单位：`d` 天、`w` 周、`h` 小时、`m` 月。例：`10d`、`2w`。
- 里程碑：`任务名 :milestone 任务ID, 日期, 0d`
- 任务名含特殊字符（如括号、冒号）时加引号：`"需求分析 (v2)" :a1, 2026-08-01, 5d`。

## 状态标记

在任务名前加前缀，`done` 已完成、`active` 进行中、`crit` 关键路径、`crit, done` 组合：

````markdown
```mermaid
gantt
    title 进度
    dateFormat YYYY-MM-DD
    section 开发
        模块A  :done, a1, 2026-08-01, 5d
        模块B  :active, a2, after a1, 5d
        模块C  :crit, a3, after a2, 5d
```
````

## 常见坑

- `after <任务ID>` 依赖的必须是**已定义的**任务 ID，不能循环依赖。
- 任务名、ID 之间用冒号分隔；整个任务定义里不能有多余的冒号（需要冒号就加引号）。
- 忘记 `dateFormat` 时默认是 `YYYY-MM-DD`，但写明更稳。
- `milestone` 关键字的顺序：`任务名 :milestone 任务ID, 日期, 0d`。
